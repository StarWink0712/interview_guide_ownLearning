## 一、四大指标分别在哪记录

下图展示了一轮完整对话的管线，标注了每个指标的采集点：

```
用户说话 → ASR 识别 → 点击提交 → LLM 生成回复 → TTS 合成语音 → AI 播放完毕
  │          │           │           │              │              │
  │          │           │           │              │              │
  │     [1] final_     [2]        [3] first_    [4] tts.      [5] turn.
  │      segments    merge_      token_latency  duration      duration
  │      (Counter)   wait         (Timer)        (Timer)       (Timer)
  │                  (Timer)     [3] llm.                     [5] turn.
  │                              duration                     completed
  │                              (Timer)                      (Counter)
  │                              [3] llm.calls
  │                              (Counter)
```

- 设计上与文字面试评估对齐，前端可复用同一套渲染组件

## 三张表的 ER 关系

```
voice_interview_sessions (1) ──< (N) voice_interview_messages
         │
         │ 1:1
         │
         └── voice_interview_evaluations
```

- 一个会话有多条对话消息（按 `sequence_num` 排序）
- 一个会话最多有一份评估结果
- 删除会话时级联删除消息和评估
