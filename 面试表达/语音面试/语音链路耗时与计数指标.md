## 三、结构化日志（SLF4J）

全部关键路径都有 `log.info` 记录，包含 `sessionId`：

```
WebSocket 连接建立/关闭
  → 接收音频大小（超过 200KB 还打 WARN）
  → ASR 合并触发 LLM
  → LLM 首 token / 完整回复
  → TTS 合成开始 / 完成
  → 整轮完成 / 失败
  → 阶段切换
```

## 四、WebSocket 运行时状态（内存）

在 [VoiceInterviewWebSocketHandler 的 SessionState 内部类](file:///Users/ogawaaya/Desktop/学习/interview_guide/interview-guide-optimize/app/src/main/java/interview/guide/modules/voiceinterview/handler/VoiceInterviewWebSocketHandler.java#L1535-L1549) 中维护：

| 字段                          | 用途                        |
| :-------------------------- | :------------------------ |
| `processing`（AtomicBoolean） | CAS 锁，防止并发触发 LLM 管线       |
| `aiSpeaking`（AtomicBoolean） | AI 正在播放 TTS，期间丢弃麦克风回声     |
| `aiSpeakEndAt`（AtomicLong）  | AI 播放后的 800ms 冷却期         |
| `mergeBuffer`               | 多段 ASR 定稿拼接缓冲区            |
| `lastSttActivityAt`         | 最近 ASR 活动时间，用于 5 分钟超时暂停检测 |

***

也就是说，你的语音面试不是只记录了对话内容，而是从 **ASR → LLM → TTS → 整轮** 四个环节都有独立的耗时和计数指标，加上持久化的消息/会话/评估数据，以及全链路结构化日志。这是一个比较完整的可观测性方案。
