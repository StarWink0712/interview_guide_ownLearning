<br />

下面是从会话创建到评估完成的全局流程图：

***

```
 ═══════════════════════════════════ ① 会话创建（REST API） ═══════════════════════════════════

  POST /api/voice-interview/sessions
   │
   └─ VoiceInterviewService.createSession()
        │
        ├─ 构建 VoiceInterviewSessionEntity
        │    skill_id, difficulty, role_type, llm_provider, planned_duration
        │    intro/tech/project/hr_enabled, current_phase, resume_id
        │
        ├─ sessionRepository.save(session)  ────▶  voice_interview_sessions 表
        │
        ├─ cacheSession(saved)  ──────────────▶  Redis（Key: voice:session:{id}）
        │
        └─ 返回 SessionResponseDTO { sessionId, wsUrl }


 ═══════════════════════════════════ ② WebSocket 连接建立 ═══════════════════════════════════

  wss://host/ws/voice-interview/{sessionId}
   │
   └─ VoiceInterviewWebSocketHandler.afterConnectionEstablished()
        │
        ├─ 配置消息大小限制（256KB）
        ├─ 包装为 ConcurrentWebSocketSessionDecorator（防并发写入，超时10s，缓冲512KB）
        │
        ├─ 存入内存 Map：
        │    sessions.put(sessionId, safeSession)
        │    sessionStates.put(sessionId, new SessionState())
        │    lastActivityTime.put(sessionId, now)
        │
        ├─ startDashScopeStt(sessionId)
        │    └─ QwenAsrService.startTranscription()
        │         └─ 与 DashScope 建立 ASR WebSocket（qwen3-asr-flash-realtime）
        │             注册 3 个回调：onFinal / onPartial / onError
        │
        ├─ 发送欢迎消息：{ type: "control", action: "welcome" }
        │
        └─ triggerOpeningQuestionIfNeeded() [虚拟线程异步]
             │
             ├─ 检查历史消息（有则跳过，防重连重复开场）
             ├─ buildOpeningQuestion()：技能模板选择
             ├─ sendTextMessage() → 前端字幕
             ├─ saveMessage(sessionId, null, aiReply) → voice_interview_messages 表
             └─ sendAudio() → 播放开场问题语音
                  │
                  └─ 优先从 openingAudioCache（@PostConstruct 预热缓存）取 WAV
                     未命中 → ttsService.synthesize() → convertPcmToWav()


 ═══════════════════════════════ ③ 实时语音管线（核心循环） ═══════════════════════════════

  前端每 100ms 推一帧 PCM 音频（Base64 JSON）
   │  { type: "audio", data: "base64..." }
   │
   └─ handleTextMessage() → 消息分发 switch(type)
        │
        ├─ "audio" → handleUserAudio()
        │    │
        │    ├─ AI 回声冷却检查：aiSpeaking || aiSpeakEndAt + 800ms 未过期 → 丢弃
        │    │
        │    ├─ Base64 解码 → PCM byte[]
        │    │
        │    ├─ sttService.sendAudio(sessionId, audioData)
        │    │    └─ DashScope ASR WebSocket
        │    │         ├─ 成功 →
        │    │         └─ 失败 → restartDashScopeStt() 重连 + 15次重试 × 80ms
        │    │
        │    └─ handleSttResult():
        │         │
        │         ├─ partial（非定稿）→ sendSubtitle(isFinal=false) → 实时字幕
        │         │                     markSttActivity()
        │         │
        │         └─ completed（定稿） → incrementCounter(asr.final_segments)
        │                                 state.appendFinalSttSegment(text)
        │                                    └─ 拼入 mergeBuffer（AtomicReference CAS）
        │                                 sendSubtitle(isFinal=false)
        │
        ├─ "control" → handleControl()
        │    │
        │    ├─ action="submit" → flushMergedUtteranceToLlm()
        │    │    │                [见下方 ④ 展开]
        │    │    │
        │    ├─ action="end_interview" → interviewService.endSession()
        │    │    │                        [见下方 ⑥ 展开]
        │    │    │
        │    └─ action="start_phase" → interviewService.startPhase(phase)
        │                              → DB 更新 currentPhase + 刷新 Redis 缓存
        │
        └─ 每次消息到达 → lastActivityTime 更新（防超时暂停）


 ════════════════════════════════ ④ 用户提交 → LLM+TTS 管线 ════════════════════════════════

  handleControl("submit") → flushMergedUtteranceToLlm()

   │
   ├─ CAS 并发锁：state.processing.compareAndSet(false, true)
   │    失败 → 排期 400ms 后重试
   │
   ├─ 取出 mergeBuffer：userText = state.takeMergeBufferAndClear()
   ├─ recordTimerMillis(asr.merge_wait)     ← 从第一段 ASR 定稿到提交的等待时间
   ├─ state.setAccumulatedText(userText)
   │
   ├─ voicePipelineExecutor.execute() [虚拟线程]
   │    │
   │    └─ triggerLlmResponse()
   │         │
   │         ├─ turnStartNanos = System.nanoTime()
   │         ├─ state.aiSpeaking.set(true)
   │         │
   │         ├─ getSessionEntity(sessionId)  → Redis 缓存 → DB 回源
   │         ├─ getHistory(sessionId)        → voice_interview_messages 表
   │         │                                  (按 sequence_num ASC)
   │         │
   │         ├─ llmService.chatStreamSentences(..., onToken, onSentence)
   │         │    │
   │         │    ├─ buildPromptContext(): System Prompt + 对话历史 + 用户输入
   │         │    │    └─ 关联简历 → resumeRepository.findById() 注入上下文
   │         │    │
   │         │    └─ chatClient.prompt()...stream().content()
   │         │         │
   │         │         ├─ 每个 token：
   │         │         │   ├─ hasTerminalSince(token)?  → onSentence.accept(句子)
   │         │         │   │     └─ CompletableFuture → ttsService.synthesize(句子)
   │         │         │   │          └─ QwenTtsService：独立 WS → commit → PCM
   │         │         │   │
   │         │         │   └─ 节流条件满足?  → onToken.accept(文本) → sendTextMessage()
   │         │         │        (≥180ms 且 ≥12 字符增量)
   │         │         │
   │         │         └─ .blockLast()：流结束
   │         │              └─ 尾句兜底 → onSentence.accept(剩余文本) → TTS
   │         │
   │         ├─ recordTimerSinceNanos(llm.first_token_latency)  [仅流式]
   │         ├─ recordTimerSinceNanos(llm.duration)
   │         ├─ incrementCounter(llm.calls, streaming=true/false)
   │         │
   │         ├─ sendSubtitle(userText, isFinal=true)     → 前端定稿字幕
   │         ├─ sendTextMessage(aiReply)                  → 前端 AI 完整文本
   │         │
   │         ├─ saveMessage(sessionId, userText, aiReply) ──▶  voice_interview_messages 表
   │         │    └─ messageType="DIALOGUE", phase, sequenceNum, timestamp
   │         │
   │         ├─ 等待所有 TTS CompletableFuture
   │         │    │
   │         │    ├─ 分块模式：每句完成 → sendAudioChunk(wav, index, isLast)
   │         │    └─ 合并模式：全部完成 → 拼接 PCM → convertPcmToWav → sendAudio()
   │         │
   │         ├─ recordTimerSinceNanos(tts.duration)
   │         ├─ 空音频? → incrementCounter(tts.empty_audio)
   │         │
   │         ├─ state.aiSpeaking.set(false)
   │         ├─ state.aiSpeakEndAt = now + 800ms（冷却期，防回声）
   │         │
   │         ├─ recordTimerSinceNanos(turn.duration, success)
   │         ├─ incrementCounter(turn.completed, success)
   │         │
   │         └─ 异常分支：
   │              ├─ recordTimerSinceNanos(turn.duration, failure)
   │              ├─ incrementCounter(turn.completed, failure)
   │              ├─ incrementCounter(errors, stage=turn)
   │              └─ sendError(session, "AI响应失败")
   │
   └─ finally: state.processing.set(false), state.processingThread = null


 ═══════════════════════════════ ⑤ WebSocket 消息类型汇总 ═══════════════════════════════

  前端 → 服务端：                      服务端 → 前端：
  ┌──────────────────────────┐       ┌──────────────────────────────┐
  │ type: "audio"            │       │ type: "subtitle"             │
  │   data: Base64(PCM)      │       │   text, isFinal              │
  ├──────────────────────────┤       ├──────────────────────────────┤
  │ type: "control"          │       │ type: "text"                 │
  │   action: submit         │       │   content: String            │
  │          end_interview   │       ├──────────────────────────────┤
  │          start_phase     │       │ type: "audio"                │
  ├──────────────────────────┤       │   data: Base64(WAV)          │
  │                          │       │   text: String               │
  │                          │       ├──────────────────────────────┤
  │                          │       │ type: "audio_chunk"          │
  │                          │       │   data, index, isLast        │
  │                          │       ├──────────────────────────────┤
  │                          │       │ type: "control"              │
  │                          │       │   action: welcome            │
  │                          │       │          pause_timeout_warning│
  │                          │       │          pause_timeout       │
  │                          │       ├──────────────────────────────┤
  │                          │       │ type: "error"                │
  │                          │       │   message: String            │
  └──────────────────────────┘       └──────────────────────────────┘


 ═══════════════════════════════ ⑥ 会话生命周期管理 ═══════════════════════════════

  正常结束：
    handleControl("end_interview")
      → interviewService.endSession()
           ├─ endTime = now
           ├─ status = COMPLETED
           ├─ currentPhase = COMPLETED
           ├─ actualDuration = between(startTime, now).toSeconds()
           ├─ evaluateStatus = PENDING
           ├─ sessionRepository.save()   ──▶  voice_interview_sessions 表
           ├─ invalidateSessionCache()
           └─ voiceEvaluateStreamProducer.sendEvaluateTask()
                └─ XADD voice:evaluate:stream  ──▶  Redis Stream

  WebSocket 断连兜底：
    afterConnectionClosed()
      ├─ 中断 LLM/TTS 虚拟线程 → processingThread.interrupt()
      ├─ sttService.stopTranscription()  → 关闭 ASR WebSocket
      ├─ sessions.remove() / sessionStates.remove() / lastActivityTime.remove()
      └─ interviewService.endSessionIfInProgress()
           └─ 仅 IN_PROGRESS 状态才执行，不重复投递评估

  暂停（前端主动）：
    PUT /pause → interviewService.pauseSession()
      ├─ pausedAt = now
      ├─ status = PAUSED
      ├─ sessionRepository.save()  ──▶  voice_interview_sessions 表
      └─ 关闭 WS + 停止 ASR + 清除内存

  恢复：
    PUT /resume → 重新建立 WebSocket 连接（流程同 ②）
      └─ resumeSession(): resumedAt = now, status = IN_PROGRESS
           └─ 有历史消息 → 不重复发开场问题

  超时自动暂停：
    @Scheduled(fixedRate=30000) checkPauseTimeout()
      ├─ 空闲 > 4分30秒 → sendPauseWarning()
      └─ 空闲 > 5分钟   → handlePauseTimeout()
                            ├─ sendMessage("pause_timeout")
                            ├─ interviewService.pauseSession("timeout")
                            ├─ session.close()
                            ├─ sttService.stopTranscription()
                            └─ 清除所有内存 Map


 ═══════════════════════════════ ⑦ 异步评估链路 ═══════════════════════════════

  Redis Stream 消费循环：

  VoiceEvaluateStreamConsumer [AbstractStreamConsumer 模板]
   │
   ├─ 解析消息：taskId, sessionId
   ├─ markProcessing()
   │    ├─ asyncTaskService.markProcessing(taskId)  → 统一任务表
   │    └─ voiceInterviewService.updateEvaluateStatus(PROCESSING)  → voice_interview_sessions
   │
   ├─ processBusiness()
   │    ├─ 会话已被删除? → AsyncTaskCancelledException → markCancelled → ACK
   │    ├─ 评估结果已存在? → 幂等跳过
   │    └─ evaluationService.generateEvaluation(sessionId)
   │         │
   │         ├─ getSession(sessionId)          → voice_interview_sessions
   │         ├─ messageRepository.findBySessionId()  → voice_interview_messages
   │         │
   │         ├─ 无消息?
   │         │    └─ saveEmptyEvaluationTransactional()
   │         │         └─ 写入空评估 → voice_interview_evaluations 表
   │         │            overallScore=0, feedback="未形成有效对话记录"
   │         │
   │         ├─ 有消息 → buildQaRecords(messages)
   │         │    └─ AI 文本=问题，用户文本=答案，关键词推断分类
   │         │
   │         ├─ UnifiedEvaluationService.evaluate(chatClient, qaRecords, ...)
   │         │    │
   │         │    ├─ 阶段1：分批 LLM 评估 (batchSize=8)
   │         │    │    └─ 单批失败 → null，合并阶段零分兜底
   │         │    │
   │         │    ├─ 阶段2：合并批次
   │         │    │    ├─ mergeQuestionEvaluations: 缺失→0分
   │         │    │    ├─ mergeOverallFeedback: 空→兜底文本
   │         │    │    └─ mergeListItems: 去重限8条
   │         │    │
   │         │    └─ 阶段3：LLM 二次汇总
   │         │         └─ 失败 → 降级到批次聚合结果
   │         │
   │         └─ saveEvaluationTransactional(sessionId, report)
   │              └─ 写入 → voice_interview_evaluations 表
   │                   overallScore, overallFeedback, questionEvaluationsJson,
   │                   strengthsJson, improvementsJson, referenceAnswersJson
   │
   ├─ markCompleted()
   │    ├─ asyncTaskService.markCompleted(taskId)
   │    └─ voiceInterviewService.updateEvaluateStatus(COMPLETED)
   │
   └─ 失败重试（最多3次）：
        retryMessage() → XADD voice:evaluate:stream（retryCount++）
        │
        └─ 超过3次 → markFailed()
             ├─ asyncTaskService.markDeadLetter()
             └─ voiceInterviewService.updateEvaluateStatus(FAILED, error)

  前端轮询：GET /api/voice-interview/sessions/{id}/evaluation
    → VoiceInterviewEvaluationService.getEvaluation()
       → evaluationRepository.findBySessionId() → voice_interview_evaluations
       → JSON 反序列化 → VoiceEvaluationDetailDTO


 ═══════════════════════════════ ⑧ 数据持久化全景 ═══════════════════════════════

  ┌─────────────────────────────────────────────────────────────────────┐
  │                        PostgreSQL                                    │
  │                                                                      │
  │  voice_interview_sessions          voice_interview_messages          │
  │  ┌──────────────────────┐          ┌──────────────────────┐          │
  │  │ id (PK)              │ 1───N   │ id (PK)              │          │
  │  │ user_id              │◄────────│ session_id (FK)      │          │
  │  │ skill_id             │         │ message_type         │          │
  │  │ difficulty           │         │ phase (ENUM)         │          │
  │  │ role_type            │         │ user_recognized_text │          │

  │  │ current_phase (ENUM) │         │ sequence_num         │          │
  │  │ status (ENUM)        │         │ timestamp            │          │
  │  │ planned_duration     │         │ created_at           │          │
  │  │ actual_duration      │         └──────────────────────┘          │
  │  │ start_time           │                                           │
  │  │ end_time             │         voice_interview_evaluations       │
  │  │ paused_at            │         ┌──────────────────────┐          │
  │  │ resumed_at           │  1:1    │ id (PK)              │          │
  │  │ evaluate_status(ENUM)│◄───────│ session_id (UNIQUE)  │          │
  │  │ evaluate_error       │         │ overall_score        │          │
  │  │ created_at           │         │ overall_feedback(TEXT)│         │
  │  │ updated_at           │         │ question_evals_json  │          │
  │  └──────────────────────┘         │ strengths_json       │          │
  │                                   │ improvements_json    │          │
  │  Redis                            │ reference_answers_json│         │
  │  ┌──────────────────────┐         │ interviewer_role     │          │
  │  │ voice:session:{id}   │         │ interview_date       │          │
  │  │ (会话缓存, RBucket)   │         │ created_at           │          │
  │  ├──────────────────────┤         └──────────────────────┘          │
  │  │ ratelimit:*          │                                           │
  │  │ (限流计数器, Lua)     │         ┌──────────────────────┐          │
  │  ├──────────────────────┤         │ Prometheus/Grafana    │          │
  │  │ voice:evaluate:stream│         │ (Micrometer指标)      │          │
  │  │ (评估任务队列)        │         │ app.voice.interview.* │          │
  │  └──────────────────────┘         └──────────────────────┘          │
  └─────────────────────────────────────────────────────────────────────┘


 ═══════════════════════════════ ⑨ SessionState 运行时状态 ═══════════════════════════════

  sessions Map:        sessionId → ConcurrentWebSocketSessionDecorator
  sessionStates Map:   sessionId → SessionState
                         ├─ accumulatedText:    AtomicReference<String>  当前轮累积文本
                         ├─ processing:         AtomicBoolean            CAS 锁防并发
                         ├─ aiSpeaking:         AtomicBoolean            TTS 播放中
                         ├─ aiSpeakEndAt:       AtomicLong               冷却截止时间(ms)
                         ├─ mergeBuffer:        AtomicReference<String>  ASR 片段拼接
                         ├─ mergeStartedAt:     AtomicLong               拼接计时起点
                         ├─ lastSttActivityAt:  AtomicLong               STT 活动时间
                         └─ processingThread:   Thread (volatile)        虚拟线程引用（断连可interrupt）
  lastActivityTime:    sessionId → timestamp(millis)   5分钟超时检测
  openingAudioCache:   text → byte[] (WAV)            @PostConstruct 预热
```

***

这个图覆盖了语音面试的完整生命周期：从 REST 创建会话 → WebSocket 连接建立 → ASR 实时识别 → 用户提交触发 LLM+TTS 管线 → 消息持久化 → 会话结束/暂停/超时 → 异步评估生成 → 评估结果落库，以及每个环节涉及的数据存储和指标记录。
