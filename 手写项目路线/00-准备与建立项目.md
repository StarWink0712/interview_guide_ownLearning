# 00 准备与建立项目

## 本阶段目标

只完成三件事：

1. 建立一个干净的新项目。
2. 启动 Spring Boot。
3. 访问一个最简单的 HTTP 接口。

这一阶段不要连接 AI、Redis、对象存储或 pgvector。

## 1. 建立练习项目目录

建议把练习项目建在当前仓库根目录下：

```text
interview-guide-rebuild/
```

最终目录大致如下：

```text
interview-guide-rebuild/
├── build.gradle
├── settings.gradle
├── gradlew
├── gradlew.bat
├── gradle/
└── src/
    ├── main/
    │   ├── java/interview/guide/
    │   └── resources/
    └── test/
        └── java/interview/guide/
```

新项目先使用单模块结构。当前参考项目虽然在根 Gradle 工程下包含 `app` 子模块，但学习版不需要先引入这层复杂度。

## 2. 使用 Spring Initializr

在 Spring Initializr 中选择：

```text
Project: Gradle - Groovy
Language: Java
Spring Boot: 4.0.x
Group: interview.guide
Artifact: interview-guide-rebuild
Name: interview-guide-rebuild
Package name: interview.guide
Packaging: Jar
Java: 21
```

第一批依赖只选择：

```text
Spring Web MVC
Validation
Spring Data JPA
PostgreSQL Driver
Lombok
```

不要一次加入 Spring AI、Redis、WebSocket、Tika、S3 和 pgvector。

## 3. 检查 `build.gradle`

第一阶段需要的核心依赖类似：

```groovy
dependencies {
  implementation 'org.springframework.boot:spring-boot-starter-webmvc'
  implementation 'org.springframework.boot:spring-boot-starter-validation'
  implementation 'org.springframework.boot:spring-boot-starter-data-jpa'

  runtimeOnly 'org.postgresql:postgresql'

  compileOnly 'org.projectlombok:lombok'
  annotationProcessor 'org.projectlombok:lombok'

  testImplementation 'org.springframework.boot:spring-boot-starter-test'
  testRuntimeOnly 'org.junit.platform:junit-platform-launcher'
}
```

确认 Java 版本：

```groovy
java {
  toolchain {
    languageVersion = JavaLanguageVersion.of(21)
  }
}
```

## 4. 先写启动类

文件：

```text
src/main/java/interview/guide/App.java
```

代码：

```java
package interview.guide;

import org.springframework.boot.SpringApplication;
import org.springframework.boot.autoconfigure.SpringBootApplication;

@SpringBootApplication
public class App {

  public static void main(String[] args) {
    SpringApplication.run(App.class, args);
  }
}
```

此时只理解两件事：

- `@SpringBootApplication` 是应用入口和组件扫描起点。
- `SpringApplication.run` 创建 Spring 容器并启动 Web 服务。

## 5. 暂时使用 H2 启动

为了避免第一天就处理 PostgreSQL 环境问题，练习项目可以先增加：

```groovy
runtimeOnly 'com.h2database:h2'
```

文件：

```text
src/main/resources/application.yml
```

内容：

```yaml
server:
  port: 8081

spring:
  application:
    name: interview-guide-rebuild
  datasource:
    url: jdbc:h2:mem:interview_guide
    driver-class-name: org.h2.Driver
    username: sa
    password:
  jpa:
    hibernate:
      ddl-auto: create-drop
    show-sql: true
```

使用 `8081` 是为了避免和当前项目的 `8080` 冲突。

完成第一个 CRUD 后，再切换 PostgreSQL。

## 6. 写健康检查接口

文件：

```text
src/main/java/interview/guide/common/HealthController.java
```

代码：

```java
package interview.guide.common;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RequestMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
@RequestMapping("/api")
public class HealthController {

  @GetMapping("/health")
  public String health() {
    return "ok";
  }
}
```

这个临时接口只用于证明：

```text
浏览器/curl
  → DispatcherServlet
  → HealthController
  → JSON/文本响应
```

## 7. 启动与验证

在练习项目目录执行：

```bash
./gradlew bootRun
```

另开终端：

```bash
curl http://localhost:8081/api/health
```

预期：

```text
ok
```

运行测试：

```bash
./gradlew test
```

## 本阶段必须讲清楚
