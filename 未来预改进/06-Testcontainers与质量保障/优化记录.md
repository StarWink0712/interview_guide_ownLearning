# 06-Testcontainers 与质量保障 - 优化记录

## 本次优化日期

2026-05-15

## 优化目标

围绕真实基础设施依赖补齐集成测试能力，让项目在不破坏现有 H2/Mock
单元测试的前提下，可以通过独立任务验证 Redis Stream、PostgreSQL pgvector
与 S3 兼容对象存储等关键链路。

## 代码优化内容

1. 增加 Testcontainers 依赖与独立测试任务
   - 在 `gradle/libs.versions.toml` 增加 Testcontainers 版本与依赖别名。
   - 在 `app/build.gradle` 增加 Testcontainers JUnit Jupiter、PostgreSQL、core 依赖。
   - 调整默认 `test` 任务排除 `container` tag，避免日常测试依赖 Docker。
   - 新增 `integrationTest` 任务，仅运行 `container` tag 测试。

2. 新增容器集成测试基类
   - 新增 `app/src/test/java/interview/guide/testsupport/BaseIntegrationTest.java`。
   - 统一启动 PostgreSQL + pgvector、Redis、MinIO。
   - 通过 `@DynamicPropertySource` 注入 datasource、Redisson、对象存储配置。
   - 使用 `@Testcontainers(disabledWithoutDocker = true)`，无 Docker 时跳过容器测试。
   - 开启测试上下文 lazy initialization，避免无关消费者与外部服务 Bean 提前启动。

3. 新增 Redis Stream 集成测试
   - 新增 `RedisStreamIntegrationTest`。
   - 覆盖消费者组创建、消息写入、消费者组读取、ACK。
   - 覆盖 pending 消息被其他消费者 `autoClaim` 后 ACK 的恢复路径。

4. 新增对象存储集成测试
   - 新增 `FileStorageServiceIntegrationTest`。
   - 使用 MinIO 容器验证简历文件上传、URL 生成、下载内容一致性和删除。
   - 测试前调用 `ensureBucketExists()` 验证 bucket 自动创建能力。

5. 新增 PostgreSQL pgvector 集成测试
   - 新增 `PostgresPgvectorIntegrationTest`。
   - 验证 pgvector 扩展可创建。
   - 验证 PostgreSQL 容器内可以执行向量距离计算 SQL。

6. 新增 RAG 最小链路测试
   - 新增 `KnowledgeBaseRagIntegrationTest`。
   - 使用 Mock `VectorStore` 避免外部 Embedding 调用。
   - 验证文档分块写入时 metadata 包含 `kb_id`。
   - 验证过滤表达式失败时 fallback 检索仍按 kbId 本地过滤。
   - 验证无命中时返回空列表。

7. 新增结构化输出质量测试
   - 新增 `StructuredOutputInvokerTest`。
   - 覆盖合法 JSON 解析成功。
   - 覆盖 Markdown 包裹的非法 JSON 触发重试后成功。
   - 覆盖未转义引号的本地修复。
   - 覆盖超过最大重试次数后抛出 `BusinessException`。

8. 修正测试配置缩进
   - 修正 `app/src/test/resources/application-test.yml` 中 Spring AI chat options
     与 `app.ai.providers.dashscope` 的 model 缩进。
   - 为 dashscope 测试 provider 补充 embedding 配置，便于测试上下文初始化。

## 验证结果

已执行：

```bash
./gradlew :app:compileTestJava
./gradlew :app:test --tests 'interview.guide.common.ai.StructuredOutputInvokerTest' --tests 'interview.guide.modules.knowledgebase.KnowledgeBaseRagIntegrationTest'
./gradlew :app:integrationTest --tests 'interview.guide.common.async.RedisStreamIntegrationTest'
./gradlew :app:integrationTest
./gradlew :app:test
```

结果：

- `compileTestJava` 通过。
- 新增结构化输出与 RAG 测试通过。
- 默认 `:app:test` 通过，且不会运行 container tag 测试。
- 当前环境未提供可用 Docker，`integrationTest` 中的 Redis、MinIO、pgvector
  容器测试被 Testcontainers 自动跳过，构建通过。

## 后续建议

1. 在 CI 中提供 Docker runner 后启用 `./gradlew :app:integrationTest`。
2. 后续可继续补充真实 pgvector RAG 检索测试，使用测试 EmbeddingModel 生成固定向量。
3. 可把 Redis Stream 消费者失败重试、FAILED 标记链路接入容器集成测试。
4. 可增加文件解析 + 对象存储 + 数据库补偿删除的端到端测试。
