# 07-前端管理控制台与测试入口 - 优化记录

## 本次优化日期

2026-05-15

## 优化目标

围绕前 6 个后端/工程化改进补齐前端演示入口，优先满足面试展示、调试验证和功能对应关系。
本次不做复杂权限系统，也不追求生产级运营后台；目标是让 AI 调用观测、RAG 评测、异步任务、
指标面板和自适应面试能力在前端可以被看到、点到、讲清楚。

## 前端优化内容

1. 新增管理控制台路由与导航入口
   - 在 `frontend/src/App.tsx` 新增 `/admin` 系列路由。
   - 在 `frontend/src/constants/routes.ts` 补充管理路由常量。
   - 在 `frontend/src/components/Layout.tsx` 侧边栏新增“管理控制台”入口。

2. 新增管理页面
   - `AdminDashboardPage.tsx`：控制台总览入口。
   - `AiTracePage.tsx`：AI 调用日志、筛选、调用详情、RAG trace 详情与命中文档片段。
   - `RagEvalPage.tsx`：评测集创建、case 添加、TopK/minScore 策略运行、run 对比表。
   - `AsyncTaskPage.tsx`：异步任务列表、状态筛选、失败原因查看、重试与取消入口。
   - `MonitoringPage.tsx`：AI 成功率、RAG 平均命中数、异步任务失败数、语音延迟摘要。
   - `AdaptiveInterviewInsightPage.tsx`：按 sessionId 查看能力画像雷达图和自适应决策时间线。

3. 新增 API 封装
   - `aiObservability.ts`：AI invocation、RAG trace、RAG eval 类型与接口。
   - `asyncTask.ts`：异步任务类型、筛选、重试、取消接口。
   - `monitoring.ts`：业务指标摘要接口。
   - `ragEval.ts`：RAG 评测接口导出入口。

4. 新增管理通用组件
   - `AdminNav.tsx`：管理控制台页内导航。
   - `MetricCard.tsx`：指标卡片。
   - `StatusBadge.tsx`：统一展示 PENDING、PROCESSING、COMPLETED、FAILED、DEAD_LETTER 等状态。
   - `TraceTimeline.tsx`：RAG trace 时间线。
   - `RagChunkList.tsx`：RAG 命中 chunk 展示。
   - `TaskTable.tsx`：异步任务表格。
   - `EvalRunResultTable.tsx`：RAG 评测 run 对比表。
   - `ConfirmActionButton.tsx`：重试、取消等确认动作按钮。

5. 优化 RAG 流式 traceId 处理
   - 后端流式 RAG 返回中新增独立 SSE `trace` event。
   - 前端 `ragChatApi.sendMessageStream()` 识别 `event: trace`，保存 traceId，不写入回答正文。
   - 知识库问答页在回答消息下方展示 Trace 短链，可跳转到 `/admin/ai-traces?traceId=...`。

6. 补齐 RAG 评测查询接口对应关系
   - 后端补充 `GET /api/ai-observability/rag-eval/datasets`。
   - 后端补充 `GET /api/ai-observability/rag-eval/datasets/{id}`。
   - 这样前端 RAG 评测页的评测集列表与详情接口不再只是预留。
