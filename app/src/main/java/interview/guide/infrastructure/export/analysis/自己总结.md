itext8是java和.NET生态最成熟的pdf处理库，导入依赖后。

该方法通过 `ByteArrayOutputStream` 在内存中构建 PDF，避免落盘产生临时文件。首先加载项目内嵌的朱雀仿宋字体（`FORCE_EMBEDDED` + `IDENTITY_H`）保证中文在任何设备上正常显示，然后依次向 `Document` 追加内容：居中的蓝色加粗标题、文件名和上传时间等基本信息、根据分数动态着色（≥80 绿/≥60 黄/<60 红）的总分，接着用两列百分比的 `Table` 渲染项目经验、技能匹配度等五个维度的评分明细，再以纯文本段落输出简历摘要，以 `•` 列表形式输出优势亮点，以优先级标签 + 分类 + 问题 + 建议的结构化方式输出改进建议。所有文本都先经过 `sanitizeText()` 正则清洗掉 emoji 等字体不支持的字符，最后 `document.close()` 收尾并将完整 PDF 以 `byte[]` 返回给调用方。
