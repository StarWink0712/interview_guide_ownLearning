

### 1. `resumes` 表（[ResumeEntity](file:///Users/ogawaaya/Desktop/学习/interview_guide/interview-guide-optimize/app/src/main/java/interview/guide/modules/resume/model/ResumeEntity.java)）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | BIGINT 自增 | 主键 |
| `file_hash` | VARCHAR(64) UNIQUE | SHA-256，用于去重 |
| `original_filename` | VARCHAR | 原始文件名 |
| `file_size` | BIGINT | 字节数 |
| `content_type` | VARCHAR | MIME 类型 |
| `storage_key` / `storage_url` | VARCHAR | RustFS 对象存储路径和 URL |
| **`resume_text`** | **TEXT** | **Tika 解析后的纯文本** |
| `uploaded_at` / `last_accessed_at` | DATETIME | 时间戳 |
| `access_count` | INT | 重复上传访问计数 |
| `analyze_status` | VARCHAR(20) | PENDING → COMPLETED / FAILED |
| `analyze_error` | VARCHAR(500) | 失败时的错误信息 |

### 2. `resume_analyses` 表（[ResumeAnalysisEntity](file:///Users/ogawaaya/Desktop/学习/interview_guide/interview-guide-optimize/app/src/main/java/interview/guide/modules/resume/model/ResumeAnalysisEntity.java)）

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | BIGINT 自增 | 主键 |
| `resume_id` | BIGINT FK | **外键关联 resumes.id**，`@ManyToOne` |
| `overall_score` | INT | 总分 0-100 |
| `content_score` 等 5 个维度 | INT | 各维度得分 |
| `summary` | TEXT | AI 生成的简历摘要 |
| `strengths_json` | TEXT | 优点列表（JSON 序列化） |
| `suggestions_json` | TEXT | 改进建议列表（JSON 序列化） |
| `analyzed_at` | DATETIME | 评测时间 |

### 存储流程

```
Tika 解析出 resumeText
  ↓
ResumePersistenceService.saveResume()
  ├── 计算 SHA-256 fileHash
  ├── 组装 ResumeEntity（resume_text = 解析文本, analyze_status = PENDING）
  ├── resumeRepository.save() → 写入 resumes 表
  ↓
返回 ResumeEntity（含自增 ID）
  ↓
analyzeStreamProducer.sendAnalyzeTask(resumeId, resumeText)  // 异步 AI 分析
  ↓
AnalyzeStreamConsumer 消费 → 调用 LLM → 拿到分析结果
  ↓
ResumePersistenceService.saveAnalysis()
  ├── 写入 resume_analyses 表（一条分析记录，关联 resume_id）
  └── 更新 resumes 表 analyze_status → COMPLETED
```

核心设计：**简历原文和分析结果分表存储**，同一份简历可以多次分析产生多条 `resume_analyses` 记录（通过 `resume_id` 一对多关联），前端展示历史评分变化时按时间排列即可。
