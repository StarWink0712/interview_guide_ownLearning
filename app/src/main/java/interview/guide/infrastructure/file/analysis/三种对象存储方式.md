## 存储后端切换说明

### 1. 默认配置（开发环境 - MinIO）

```yaml
# application.yml
app:
storage:
    endpoint: http://localhost:9000    # MinIO 默认端口
    access-key: minioadmin
    secret-key: minioadmin
    bucket: interview-guide
```

**适用场景**：本地开发、测试环境，数据存储在本地 MinIO 服务中。

---

### 2. 切换到 AWS S3（生产环境）

通过环境变量覆盖配置：

```bash
export APP_STORAGE_ENDPOINT=https://s3.amazonaws.com
export APP_STORAGE_ACCESS_KEY=AKIAIOSFODNN7EXAMPLE
export APP_STORAGE_SECRET_KEY=wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY
export APP_STORAGE_BUCKET=my-production-bucket
```

**适用场景**：生产环境，需要高可用、弹性扩展的云存储服务。

---

### 3. 切换到阿里云 OSS

阿里云 OSS 支持 S3 兼容模式，配置方式类似：

```bash
export APP_STORAGE_ENDPOINT=https://oss-cn-hangzhou.aliyuncs.com
export APP_STORAGE_ACCESS_KEY=LTAI5t7mXxxxxxxxxx
export APP_STORAGE_SECRET_KEY=K4p9xxxxxxxxxxxxxxxxxxxx
export APP_STORAGE_BUCKET=my-oss-bucket
```

**适用场景**：国内生产环境，需要低延迟和本地化服务。

---

### 4. 其他支持的存储服务

除了 MinIO、AWS S3、阿里云 OSS，您还可以使用：
- **腾讯云 COS**（S3 兼容模式）
- **Google Cloud Storage**（S3 兼容模式）
- **华为云 OBS**（S3 兼容模式）
- **自建分布式存储**（如 Ceph RGW）

---

## 切换优势

| 优势 | 说明 |
|------|------|
| **零代码改动** | 只需修改配置，业务代码完全不变 |
| **协议兼容** | 所有 S3 兼容存储都支持相同的 API |
| **环境隔离** | 开发用 MinIO，生产用云存储 |
| **数据迁移** | 数据可以无缝迁移到不同存储后端 |

---

## 架构优势总结

```
┌─────────────────────────────────────────────────────────────────┐
│                        业务代码层                              │
│         FileStorageService / ResumeUploadService               │
├─────────────────────────────────────────────────────────────────┤
│                       AWS S3 SDK                              │
│              (统一的 S3 API 接口)                              │
├─────────────────────────────────────────────────────────────────┤
│  ┌──────────────┐  ┌──────────────┐  ┌──────────────┐        │
│  │   MinIO      │  │   AWS S3     │  │   阿里云 OSS  │        │
│  │ (本地开发)   │  │ (生产环境)   │  │ (国内部署)   │        │
│  └──────────────┘  └──────────────┘  └──────────────┘        │
└─────────────────────────────────────────────────────────────────┘
```

这种设计使得您可以：
- **开发阶段**：使用本地 MinIO，快速启动，无需网络
- **测试阶段**：使用 MinIO 集群，模拟生产环境
- **生产阶段**：按需选择 AWS S3、阿里云 OSS 或其他云存储

**核心价值**：**避免云厂商锁定**，您可以根据成本、性能、合规要求自由选择最合适的存储方案。
