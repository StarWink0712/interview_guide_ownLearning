## SkillsTool 详解

### 📌 什么是 SkillsTool？

**SkillsTool** 是一种特殊的工具，让 AI 能够调用预定义的**技能**。

可以把 SkillsTool 理解为 AI 的"工具箱"，里面装着各种技能，AI 可以根据需要选择使用。

***

### 📁 技能文件结构

### 📄 技能文件示例

```markdown
# resources/skills/java-backend/SKILL.md

---
name: java-backend
description: 用于 Java 后端面试出题；优先围绕 Java 核心、MySQL、Redis、Spring 与项目实战
---

# Overview
你是一位 Java 后端面试官，目标是识别候选人是否具备可上线的工程能力...

# Instructions
1. 优先结合候选人简历和项目经历提问。
2. 提问顺序遵循：使用经验 -> 原理机制 -> 边界条件 -> 优化与故障。
3. 每个主问题都需要可追问...
```

**技能文件定义了 AI 的"人设"和行为规则**，就像给 AI 一份工作手册。

### 🎭 SkillsTool vs Plain ChatClient 的区别

```
┌─────────────────────────────────────────────────────────────────┐
│              带 SkillsTool 的 ChatClient                         │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   用户: "帮我出一道 Java 面试题"                                  │
│                                                                 │
│   AI 思考: 我有一个 java-backend 技能，让我调用它...              │
│                                                                 │
│   响应流程:                                                      │
│   1. AI 决定调用技能                                             │
│   2. 读取 SKILL.md 内容                                          │
│   3. 按照技能定义生成面试题                                       │
│   4. 返回结果                                                    │
│                                                                 │
│   特点: AI 会"思考"是否需要使用技能                               │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────────────────┐
│              Plain ChatClient（无 SkillsTool）                   │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   用户: "请返回 JSON 格式的面试题"                                │
│                                                                 │
│   AI 直接响应:                                                   │
│   {                                                             │
│     "question": "请解释 Java 多线程...",                         │
│     "difficulty": "medium",                                     │
│     "tags": ["java", "multithreading"]                          │
│   }                                                             │
│                                                                 │
│   特点: AI 直接返回结果，不会触发技能调用                          │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### ❓ 为什么有时需要 Plain ChatClient？

#### 问题场景：结构化输出

```java
// 使用带 SkillsTool 的 ChatClient
ChatClient client = registry.getDefaultChatClient();

InterviewQuestion question = client.prompt()
    .user("生成一道 Java 面试题，返回 JSON")
    .call()
    .entity(InterviewQuestion.class);  // 期望解析为 Java 对象

// 可能的问题：
// AI 可能先调用技能，返回的是技能调用的中间结果
// 导致 JSON 解析失败！
```

#### 解决方案：使用 Plain ChatClient

```java
// 使用 Plain ChatClient（无技能工具）
ChatClient client = registry.getPlainChatClient(null);

InterviewQuestion question = client.prompt()
    .user("生成一道 Java 面试题，返回 JSON")
    .call()
    .entity(InterviewQuestion.class);  // ✅ 直接返回 JSON，解析成功！
```

### 📊 三种 ChatClient 变体对比

| 变体          | SkillsTool |   Advisors  | 适用场景         |
| ----------- | :--------: | :---------: | ------------ |
| **Default** |     ✅ 有    |      全部     | 普通对话、面试聊天    |
| **Plain**   |     ❌ 无    |    仅安全防护    | 结构化输出（出题、评分） |
| **Voice**   |     ✅ 有    | 流式 ToolCall | 语音面试实时交互     |

```
┌─────────────────────────────────────────────────────────────────┐
│                      使用场景决策树                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   需要调用 ChatClient                                            │
│         │                                                       │
│         ├── 需要返回 JSON/结构化数据？                            │
│         │         │                                             │
│         │         ├── 是 → getPlainChatClient()                 │
│         │         │                                             │
│         │         └── 否 ↓                                      │
│         │                                                       │
│         ├── 是语音面试场景？                                      │
│         │         │                                             │
│         │         ├── 是 → getVoiceChatClient()                 │
│         │         │                                             │
│         │         └── 否 → getDefaultChatClient()               │
│         │                                                       │
└─────────────────────────────────────────────────────────────────┘
```

### 💡 总结

| 概念                   | 说明                          |
| -------------------- | --------------------------- |
| **SkillsTool**       | 让 AI 能调用预定义技能的工具            |
| **技能文件**             | `SKILL.md`，定义 AI 的"人设"和行为规则 |
| **Plain ChatClient** | 不带技能工具，确保直接返回结果             |
| **为什么需要 Plain**      | 避免 AI 触发技能调用，破坏结构化输出格式      |

**简单类比**：

- **带 SkillsTool** = 给 AI 一个工具箱，AI 会思考是否需要用工具
- **Plain ChatClient** = 不给 AI 工具箱，AI 直接回答问题
