## Advisor 详解

### 📌 什么是 Advisor？

**Advisor** 是 Spring AI 中的**拦截器/增强器**，类似于 Spring AOP 中的切面（Aspect）。它可以在请求发送前和响应返回后进行拦截处理，为 ChatClient 添加额外功能。

---

### 🎯 Advisor 的作用

```
┌─────────────────────────────────────────────────────────────────┐
│                    Advisor 拦截链                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   用户输入: "帮我出一道 Java 面试题"                              │
│                                                                 │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │ Advisor 1: SafeGuardAdvisor（安全防护）                  │  │
│   │ • 检查输入是否包含敏感词                                  │  │
│   │ • 如果敏感，直接拦截返回拒绝响应                          │  │
│   └─────────────────────────────────────────────────────────┘  │
│                              ↓                                  │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │ Advisor 2: MessageChatMemoryAdvisor（对话记忆）          │  │
│   │ • 从历史记录加载之前的对话                                │  │
│   │ • 添加到当前请求中，保持上下文连贯                        │  │
│   └─────────────────────────────────────────────────────────┘  │
│                              ↓                                  │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │ Advisor 3: ToolCallAdvisor（工具调用）                   │  │
│   │ • 如果 AI 返回工具调用请求，执行对应工具                  │  │
│   │ • 将工具结果返回给 AI，可能触发多轮调用                   │  │
│   └─────────────────────────────────────────────────────────┘  │
│                              ↓                                  │
│   ┌─────────────────────────────────────────────────────────┐  │
│   │ OpenAiChatModel → 发送到 LLM                             │  │
│   └─────────────────────────────────────────────────────────┘  │
│                              ↓                                  │
│   AI 响应: "好的，这是一道 Java 面试题..."                       │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

---

### 🔧 四种 Advisor 的作用

| Advisor | 作用 | 类比 |
|---------|------|------|
| **SafeGuardAdvisor** | 安全防护，过滤敏感内容 | 保安 |
| **MessageChatMemoryAdvisor** | 对话记忆，保持上下文连贯 | 秘书记录 |
| **ToolCallAdvisor** | 处理工具调用，支持多轮 | 翻译官 |
| **SimpleLoggerAdvisor** | 日志记录，便于调试 | 记录员 |

### 📖 详细说明

#### 1. SafeGuardAdvisor（安全防护）

```
┌─────────────────────────────────────────────────────────────────┐
│                    SafeGuardAdvisor                              │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   用户输入: "帮我写一个黑客攻击脚本"                              │
│                                                                 │
│   SafeGuardAdvisor 检测到敏感词: "黑客攻击"                      │
│                                                                 │
│   拦截请求，直接返回:                                            │
│   "抱歉，我只能协助面试相关的任务。"                              │
│                                                                 │
│   不会发送到 LLM，节省 API 调用费用                              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

#### 2. MessageChatMemoryAdvisor（对话记忆）

```
┌─────────────────────────────────────────────────────────────────┐
│                MessageChatMemoryAdvisor                          │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   第一轮对话:                                                    │
│   用户: "我叫张三"                                               │
│   AI: "你好张三！"                                               │
│                                                                 │
│   第二轮对话:                                                    │
│   用户: "我叫什么名字？"                                          │
│                                                                 │
│   MessageChatMemoryAdvisor 自动添加历史:                         │
│   [                                                             │
│     {"role": "user", "content": "我叫张三"},                     │
│     {"role": "assistant", "content": "你好张三！"},              │
│     {"role": "user", "content": "我叫什么名字？"}  ← 当前问题    │
│   ]                                                             │
│                                                                 │
│   AI 能回答: "你叫张三。"                                         │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

#### 3. ToolCallAdvisor（工具调用）

```
┌─────────────────────────────────────────────────────────────────┐
│                    ToolCallAdvisor                               │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│   用户: "帮我出一道 Java 面试题"                                  │
│                                                                 │
│   AI 返回:                                                       │
│   {                                                             │
│     "tool_calls": [{                                            │
│       "name": "interview-question",  ← 要调用面试出题技能        │
│       "arguments": "{\"topic\": \"Java\"}"                      │
│     }]                                                          │
│   }                                                             │
│                                                                 │
│   ToolCallAdvisor:                                               │
│   1. 解析工具调用请求                                            │
│   2. 执行 interview-question 技能                               │
│   3. 将结果返回给 AI                                            │
│   4. AI 生成最终回答                                            │
│                                                                 │
│   可能触发多轮工具调用，直到 AI 不再请求调用工具                   │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

#### 4. SimpleLoggerAdvisor（日志记录）

```
┌─────────────────────────────────────────────────────────────────┐
│                  SimpleLoggerAdvisor                             │

│   自动记录请求和响应日志：                                        │
│                                                                 │
│   [INFO] Request: {                                             │
│     "model": "qwen-plus",                                       │

│   }                                                             │
│                                                                 │
│   [INFO] Response: {                                            │
│     "content": "你好！有什么可以帮助你的？",                      │
│     "usage": {"prompt_tokens": 5, "completion_tokens": 10}      │
│   }                                                             │
│                                                                 │
│   便于调试和问题排查                                              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```

### 🔄 Advisor 执行顺序

```java
// 按添加顺序执行
List<Advisor> advisors = new ArrayList<>();

advisors.add(toolCallAdvisor);           // 1. 先处理工具调用
advisors.add(memoryAdvisor);             // 2. 再添加对话记忆
advisors.add(simpleLoggerAdvisor);       // 3. 记录日志
advisors.add(safeGuardAdvisor);          // 4. 最后安全检查
```

```
请求流程：
用户输入 → SafeGuardAdvisor → MemoryAdvisor → ToolCallAdvisor → LLM

响应流程：
LLM → ToolCallAdvisor → MemoryAdvisor → SimpleLoggerAdvisor → 返回用户
```

---

### 📝 配置示例

```yaml
# application.yml
app:
  ai:
    advisors:
      enabled: true

      # 工具调用配置
      tool-call-enabled: true
      tool-call-conversation-history-enabled: true
      stream-tool-call-responses: true

      # 对话记忆配置
      message-chat-memory-enabled: true
      message-chat-memory-max-messages: 50

      # 日志配置
      simple-logger-enabled: true

      # 安全防护配置
      safeguard-enabled: true
      safeguard-words:
        - 黑客
        - 攻击
        - 漏洞
```

### 🎭 类比理解

| Advisor | 类比 | 说明 |
|---------|------|------|
| **SafeGuardAdvisor** | 公司保安 | 检查进入的人是否合规 |
| **MessageChatMemoryAdvisor** | 秘书 | 记录之前的对话，提醒上下文 |
| **ToolCallAdvisor** | 翻译官 | AI 和工具之间的沟通桥梁 |
| **SimpleLoggerAdvisor** | 记录员 | 记录所有对话内容 |

```
就像公司处理客户请求：

客户请求 → 保安检查 → 秘书查找历史记录 → 翻译官处理专业问题 → 专家回答
    ↓
记录员记录全过程
```

### 💡 总结

| 问题 | 答案 |
|------|------|
| **Advisor 是什么？** | 拦截器/增强器，为 ChatClient 添加额外功能 |
| **有什么作用？** | 安全防护、对话记忆、工具调用、日志记录 |
| **执行顺序？** | 按添加顺序依次执行 |
| **可以自定义吗？** | 可以，实现 Advisor 接口即可 |

**简单来说**：Advisor 就像是给 ChatClient 装上了各种"插件"，让它更智能、更安全、更易调试。
