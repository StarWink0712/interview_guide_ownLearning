```java
public InterviewReportDTO evaluateInterview(ChatClient chatClient, String sessionId,
                                            String resumeText,
                                            List<InterviewQuestionDTO> questions) {
    // 步骤 1a：将 InterviewQuestionDTO 列表转为通用 QaRecord 列表（中间变量）

    // 步骤 1b：通过 skillService 构建技能参考上下文（中间变量）
```

#### 1) 执行的动作

#### 2) 对应代码

[UnifiedEvaluationService.java#L226-238](file:///Users/ogawaaya/Desktop/学习/interview_guide/interview-guide-optimize/app/src/main/java/interview/guide/common/evaluation/UnifiedEvaluationService.java#L226-L238)：

```java
private List<BatchResult> evaluateInBatches(ChatClient chatClient, String sessionId,
                                             String resumeContext, List<QaRecord> qaRecords,
                                             String referenceContext) {
    List<BatchResult> results = new ArrayList<>();
    for (int start = 0; start < qaRecords.size(); start += evaluationBatchSize) {
        int end = Math.min(start + evaluationBatchSize, qaRecords.size());
        List<QaRecord> batch = qaRecords.subList(start, end);
        BatchReportDTO report = evaluateBatch(chatClient, sessionId, resumeContext, referenceContext, batch);
        results.add(new BatchResult(start, end, report));
    }
    return results;
}
```

由于 `batchSize = 4`（配置值），5 题被分为 2 批：

| 批次   | 题目范围           | 包含题目                                          |
| ---- | -------------- | --------------------------------------------- |
| 批次 0 | start=0, end=4 | Q0(JVM内存), Q1(Full GC), Q2(覆盖索引), Q3(RDB/AOF) |
| 批次 1 | start=4, end=5 | Q4(秒杀系统)                                      |

#### 3) 输入/输出数据结构

**输入**：`List<QaRecord>`（5 条）、`evaluationBatchSize = 4`
**输出**：`List<BatchResult>`（2 条）

### 4.1 合并逐题评估 `mergeQuestionEvaluations()`

#### 1) 执行的动作

将两个批次的逐题评估按原始顺序合并，缺失项零分兜底。

#### 2) 对应代码

[UnifiedEvaluationService.java#L294-313](file:///Users/ogawaaya/Desktop/学习/interview_guide/interview-guide-optimize/app/src/main/java/interview/guide/common/evaluation/UnifiedEvaluationService.java#L294-L313)：

```java
private List<QuestionEvalDTO> mergeQuestionEvaluations(List<BatchResult> batchResults) {
    List<QuestionEvalDTO> merged = new ArrayList<>();
    for (BatchResult result : batchResults) {
        int expectedSize = result.endIndex() - result.startIndex();
        List<QuestionEvalDTO> current =
            result.report() != null && result.report().questionEvaluations() != null
                ? result.report().questionEvaluations()
                : List.of();
        for (int i = 0; i < expectedSize; i++) {
            if (i < current.size() && current.get(i) != null) {
                merged.add(current.get(i));          // 使用 LLM 评估结果
            } else {
                merged.add(new QuestionEvalDTO(       // 零分兜底
                    result.startIndex() + i, 0,
                    "该题未成功生成评估结果，系统按 0 分处理。", "", List.of()
                ));
            }
        }
    }
    return merged;
}
```

遍历逻辑：

```
批次 0 (expectedSize=4):
  i=0 → current[0] 存在 → 使用 LLM 评估 (Q0: score=85)
  i=1 → current[1] 存在 → 使用 LLM 评估 (Q1: score=90)
  i=2 → current[2] 存在 → 使用 LLM 评估 (Q2: score=70)
  i=3 → current[3] 存在 → 使用 LLM 评估 (Q3: score=83)

批次 1 (expectedSize=1):
  i=0 → current[0] 存在 → 使用 LLM 评估 (Q4: score=88)
```

#### 3) 输入/输出数据结构

**输入**：`List<BatchResult>`（2 条）
**输出**：`List<QuestionEvalDTO>`（5 条，与原始问答记录数完全一致）

如果批次 0 的 LLM 调用失败（`report=null`），该批次 4 题全部获得零分兜底对象。

#### 4) 依赖关系

```
mergeQuestionEvaluations()
  ├── 依赖 BatchResult（读取 report 和各题评估）
  └── 依赖 QuestionEvalDTO（构造零分兜底对象）
  └── 不依赖 LLM（纯内存合并逻辑）
```

```java
private List<String> mergeListItems(List<BatchResult> batchResults, boolean strengthsMode) {
    Set<String> merged = new LinkedHashSet<>();
    for (BatchResult result : batchResults) {
        BatchReportDTO report = result.report();
        if (report == null) continue;
        List<String> items = strengthsMode ? report.strengths() : report.improvements();
        if (items == null) continue;
        items.stream()
            .filter(item -> item != null && !item.isBlank())
            .map(String::trim)
            .forEach(merged::add);
    }
    return merged.stream().limit(8).toList();
}
```

```java
private String buildCategorySummary(List<QaRecord> qaRecords, List<QuestionEvalDTO> evaluations) {
    Map<String, List<Integer>> categoryScores = new HashMap<>();
    for (int i = 0; i < qaRecords.size(); i++) {
        QaRecord q = qaRecords.get(i);
        QuestionEvalDTO eval = i < evaluations.size() ? evaluations.get(i) : null;
        int score = 0;
        if (eval != null && q.userAnswer() != null && !q.userAnswer().isBlank()) {
            score = eval.score();
        }
        categoryScores.computeIfAbsent(q.category(), k -> new ArrayList<>()).add(score);
    }
    return categoryScores.entrySet().stream()
        .map(entry -> {
            int avg = (int) entry.getValue().stream().mapToInt(Integer::intValue).average().orElse(0);
            return String.format("- %s: 平均分 %d, 题数 %d", entry.getKey(), avg, entry.getValue().size());
        })
        .sorted()
        .collect(Collectors.joining("\n"));
}
```

| `summarizeBatchResults()`  | `buildCategorySummary()`              | 单向   | 分类得分摘要文本                                                       |
| `summarizeBatchResults()`  | `buildQuestionHighlights()`           | 单向   | 单题亮点摘要文本                                                       |
| `buildReport()`            | `EvaluationReport` 构造器                | 单向   | 所有合并结果 → 最终报告                                                  |
