### 🗂️ 具体对应关系

#### 1. **LlmProviderEntity ↔ LlmProviderRepository**

| 位置 | 作用 | 说明 |
|------|------|------|
| **LlmProviderEntity** | 数据实体类 | JPA 映射 `llm_provider` 表 |
| **LlmProviderRepository** | 数据访问接口 | 继承 `JpaRepository<LlmProviderEntity, String>` |

**对应关系**：
```java
// LlmProviderEntity - 数据模型
@Entity
@Table(name = "llm_provider")
public class LlmProviderEntity {
    @Id
    private String id;                                    // Provider ID（主键）
    
    @Column(name = "base_url")
    private String baseUrl;                               // API 基础 URL
    
    @Column(name = "api_key_nonce")
    private String apiKeyNonce;                           // 加密 nonce
    
    @Column(name = "api_key_ciphertext") 
    private String apiKeyCiphertext;                      // 加密密文
    
    @Column(name = "model")
    private String model;                                 // 模型名称
    
    @Column(name = "embedding_model")
    private String embeddingModel;                         // 嵌入模型名称
    
    @Column(name = "supports_embedding")
    private boolean supportsEmbedding;                     // 是否支持嵌入
    
    @Column(name = "enabled")
    private boolean enabled;                             // 是否启用
    
    // getter/setter 方法...
}

// LlmProviderRepository - 数据访问
public interface LlmProviderRepository extends JpaRepository<LlmProviderEntity, String> {
    List<LlmProviderEntity> findByEnabledTrueOrderByIdAsc();  // 自定义查询方法
}
```

### 🔍 数据库表结构

#### `llm_provider` 表
```sql
CREATE TABLE llm_provider (
    id VARCHAR(64) PRIMARY KEY,                          -- Provider ID（如 'dashscope'）
    base_url VARCHAR(256) NOT NULL,                     -- API 基础 URL
    api_key_nonce VARCHAR(256),                         -- 加密 nonce
    api_key_ciphertext TEXT NOT NULL,                   -- 加密密文
    model VARCHAR(128) NOT NULL,                       -- 模型名称
    embedding_model VARCHAR(128),                       -- 嵌入模型名称
    embedding_dimensions INTEGER,                       -- 嵌入维度
    supports_embedding BOOLEAN DEFAULT false,           -- 是否支持嵌入
    temperature DECIMAL(3,2),                          -- 温度参数
    enabled BOOLEAN DEFAULT true,                      -- 是否启用
    builtin BOOLEAN DEFAULT false,                     -- 是否为内置（种子数据）
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
);
```

#### `llm_global_setting` 表（单例模式）
```sql
CREATE TABLE llm_global_setting (

    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP
```

### 🔄 使用流程示例

#### 1. Provider 管理流程

```java
@Service
public class LlmProviderService {
    
    private final LlmProviderRepository providerRepository;
    private final LlmGlobalSettingRepository globalSettingRepository;
    
    // 创建 Provider
    @Transactional
    public void createProvider(LlmProviderEntity entity) {
        providerRepository.save(entity);
    }
    
    // 获取所有启用的 Provider
    public List<LlmProviderEntity> getActiveProviders() {
        return providerRepository.findByEnabledTrueOrderByIdAsc();
    }
    
    // 获取指定 Provider
    public Optional<LlmProviderEntity> getProvider(String id) {
        return providerRepository.findById(id);
    }
    
    // 更新 Provider
    @Transactional
    public void updateProvider(LlmProviderEntity entity) {
        providerRepository.save(entity);
    }
    
    // 删除 Provider
    @Transactional
    public void deleteProvider(String id) {
        providerRepository.deleteById(id);
    }
}
```

#### 2. 全局设置管理流程

```java
@Service
public class GlobalSettingService {
    
    private final LlmGlobalSettingRepository globalSettingRepository;
    
    // 获取全局设置（只有一条记录）
    public LlmGlobalSettingEntity getGlobalSetting() {
        return globalSettingRepository.findById(1L)
            .orElseThrow(() -> new RuntimeException("全局设置未初始化"));
    }
    
    // 更新默认聊天模型
    @Transactional
    public void updateDefaultChatProvider(String providerId) {
        LlmGlobalSettingEntity setting = getGlobalSetting();
        setting.setDefaultChatProviderId(providerId);
        globalSettingRepository.save(setting);
    }
    
    // 更新默认嵌入模型
    @Transactional
    public void updateDefaultEmbeddingProvider(String providerId) {
        LlmGlobalSettingEntity setting = getGlobalSetting();
        setting.setDefaultEmbeddingProviderId(providerId);
        globalSettingRepository.save(setting);
    }
}
```
