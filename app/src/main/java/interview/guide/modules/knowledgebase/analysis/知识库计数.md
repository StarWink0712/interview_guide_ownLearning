### 5. **与其他计数字段的区别**

#### 5.1 **访问计数（accessCount）**
```java
// 访问计数：每次打开知识库页面就增加
public void incrementAccessCount() {
    this.accessCount++;
    this.lastAccessedAt = LocalDateTime.now();
}
```

#### 5.2 **提问计数（questionCount）**
```java
// 提问计数：只有实际进行问答时才增加
public void incrementQuestionCount() {
    this.questionCount++;
    this.lastAccessedAt = LocalDateTime.now();
}
```

**区别**：
- **访问计数**：反映知识库的浏览热度
- **提问计数**：反映知识库的实际使用价值
