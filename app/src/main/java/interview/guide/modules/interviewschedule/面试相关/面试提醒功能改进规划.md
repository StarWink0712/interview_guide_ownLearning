# 面试提醒后续改进规划

当前版本已经实现邮件与站内提醒框架：数据库提醒计划、每分钟调度、Redis Stream、SMTP HTML 邮件、失败重试、站内提醒铃和已读状态。

后续可以按以下顺序增强：

1. 接入用户认证，在日程和提醒表增加 `userId`，解决站内提醒的数据隔离。
2. 增加提醒偏好页，让用户选择 24 小时/1 小时提醒以及是否发送邮件。
3. 使用 Flyway/Liquibase 管理 `interview_reminder` 表结构，而不是依赖 `ddl-auto=update`。
4. 为 SMTP 接入生产服务商并增加退信、垃圾邮件和发送配额监控。
5. 增加分布式调度锁或统一调度节点，进一步降低多实例重复扫描。
6. 增加运维页面，展示 PENDING、FAILED 和重试耗尽的提醒任务。
7. 如果以后需要即时推送，再在现有站内提醒表之上增加 SSE/WebSocket；持久化提醒仍作为离线兜底。

当前不计划加入短信、公众号或第三方聊天机器人，以控制项目范围。
