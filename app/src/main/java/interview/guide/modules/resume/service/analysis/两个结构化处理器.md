## 1. **BeanOutputConverter** - 响应转换器

### **作用**
```java

private final BeanOutputConverter<ResumeAnalysisResponseDTO> outputConverter;
```

**核心功能**：

- 通过**JSON Schema**引导AI输出结构化数据
- 处理**类型转换**和**字段映射**

### **实现原理**

## 2. **StructuredOutputInvoker** - 结构化输出调用器

### **作用**
```java
// 调用结构化输出调用器，用于解析AI响应
private final StructuredOutputInvoker structuredOutputInvoker;
```

**核心功能**：
- **封装重试机制**：AI调用失败时自动重试
- **异常处理**：统一处理各种异常情况
- **日志记录**：详细的调用日志和错误追踪
- **超时控制**：防止AI响应时间过长

### **实现原理**

#### **1. 重试机制**
```java
// StructuredOutputInvoker的核心调用方法
public <T> T invoke(
    ChatClient chatClient,                    // AI客户端
    String systemPrompt,                      // 系统提示词
    String userPrompt,                       // 用户提示词  
    BeanOutputConverter<T> outputConverter,  // 输出转换器
    ErrorCode errorCode,                     // 错误码
    String errorMessage,                      // 错误消息前缀
    String operationName,                     // 操作名称（日志用）
    Logger log                                // 日志记录器
) {
    // 重试逻辑
    int maxRetries = 3;
    int attempt = 0;
    
    while (attempt < maxRetries) {
        try {
            // 1. 构建完整提示词
            String fullPrompt = systemPrompt + "\n\n" + outputConverter.getFormat();
            
            // 2. 调用AI
            String aiResponse = chatClient.prompt()
                .system(fullPrompt)
                .user(userPrompt)
                .call()
                .content();
                
            // 3. 解析响应
            T result = outputConverter.convert(aiResponse);
            
            // 4. 返回成功结果
            return result;
            
        } catch (Exception e) {
            attempt++;
            log.warn("第{}次调用AI失败: {}", attempt, e.getMessage());
            
            if (attempt >= maxRetries) {
                // 重试次数用完，抛出业务异常
                throw new BusinessException(errorCode, errorMessage + e.getMessage());
            }
            
            // 等待一段时间后重试
            Thread.sleep(calculateBackoffTime(attempt));
        }
    }
    
    throw new BusinessException(errorCode, "AI调用失败");
}
```

#### **2. 退避算法**
```java
private long calculateBackoffTime(int attempt) {
    // 指数退避：1s, 2s, 4s...
    return (long) (Math.pow(2, attempt) * 1000);
}
```

#### **3. 异常处理策略**
```java
try {
    // AI调用逻辑
} catch (AiResponseParseException e) {
    // AI响应格式错误，重新生成
    log.warn("AI响应格式错误，尝试重新生成: {}", e.getMessage());
} catch (AiTimeoutException e) {
    // AI响应超时，快速重试
    log.warn("AI响应超时，快速重试: {}", e.getMessage());
} catch (AiServiceException e) {
    // AI服务错误，较长等待后重试
    log.error("AI服务错误: {}", e.getMessage());
} catch (Exception e) {
    // 其他异常，直接失败
    throw new BusinessException(errorCode, errorMessage + e.getMessage());
}
```

### **优势**
- **高可靠性**：自动重试确保服务可用性
- **容错性**：处理各种AI服务异常
- **可观测性**：详细的日志和监控
- **一致性**：统一的异常处理机制

## 3. **协同工作机制**

### **流程图**
```

    ↓

    ↓

    ↓

    ↓

    ↓

    ↓

    ↓
```

## 4. **技术优势总结**

### **BeanOutputConverter的优势**
1. **类型安全**：编译时检查JSON字段映射
2. **自动转换**：无需手动JSON解析代码
3. **文档化**：JSON Schema作为API文档
4. **验证机制**：确保数据完整性

### **StructuredOutputInvoker的优势**
1. **可靠性**：自动重试提高成功率
2. **容错性**：优雅处理各种异常
3. **监控友好**：详细的日志和指标
4. **配置灵活**：可调整重试策略

### **组合使用的优势**
1. **端到端结构化**：从自然语言到Java对象的完整转换
2. **高可用性**：重试机制确保服务稳定
3. **开发效率**：减少样板代码
4. **维护性**：统一的异常处理和日志

这两个工具的配合使用，使得**AI调用变得可靠且易于维护**，是Spring AI生态中处理结构化输出的最佳实践。
