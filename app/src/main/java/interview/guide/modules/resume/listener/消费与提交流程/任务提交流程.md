```java
public String streamAdd(String streamKey, Map<String, String> message, int maxLen) {
    // ① 通过 Redisson 获取 RStream 代理对象（轻量操作，不建新连接）
    RStream<String, String> stream = redissonClient.getStream(streamKey, StringCodec.INSTANCE);

    // ② 将 Map 包装为 Redisson 的 StreamAddArgs
    StreamAddArgs<String, String> args = StreamAddArgs.entries(message);
    if (maxLen > 0) {
        args.trimNonStrict().maxLen(maxLen);  // MAXLEN ~1000 自动裁剪
    }

    // ③ 通过 RStream 接口发送 → 底层执行 XADD 命令
    StreamMessageId messageId = stream.add(args);

    return messageId.toString();  // 如 "1747300000000-0"
}
```

✅ 你说的"通过 redisson 获取对应 streamKey 的接口，通过接口把信息添加进去"完全正确。
