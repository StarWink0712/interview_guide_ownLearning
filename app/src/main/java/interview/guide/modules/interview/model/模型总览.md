# interview.model 包 — 面试模块数据模型总览

本包包含面试模块全部 **14 个数据类**，按职责分为 4 大类：

| 分类 | 说明 | 数量 |
|------|------|------|
| **Entity** | JPA 持久化实体，与数据库表一一映射 | 2 |
| **Request** | 前端输入请求体，接收 HTTP 请求参数 | 2 |
| **Response** | 前端输出响应体，返回给前端的结构化数据 | 2 |
| **DTO** | Service 层之间传递的中转对象 | 8 |

---

## 一、Entity — JPA 持久化实体（2 个）

### 1. InterviewSessionEntity

对应数据库表 `interview_sessions`，代表一次完整的面试会话。

**核心字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `sessionId` | String | 会话 UUID，对外唯一标识 |
| `resume` | ResumeEntity | 关联的简历（@ManyToOne） |
| `skillId` | String | 面试主题，如 "java-backend" |
| `difficulty` | String | 难度：junior / mid / senior |
| `totalQuestions` | Integer | 总题数 |
| `currentQuestionIndex` | Integer | 当前题号 |
| `questionsJson` | TEXT | 所有题目的 JSON，避免查表 |
| `status` | SessionStatus | CREATED → IN_PROGRESS → COMPLETED → EVALUATED |
| `evaluateStatus` | AsyncTaskStatus | 异步评估状态：PROCESSING / COMPLETED / FAILED |
| `evaluateError` | String | 评估失败时的错误信息 |
| `overallScore` | Integer | 总分 |
| `llmProvider` | String | LLM 提供商，默认 "dashscope" |
| `abilityProfileJson` | TEXT | 自适应能力画像 JSON |
| `adaptiveTraceJson` | TEXT | 自适应追踪链 JSON |

**关联关系**：
- 与 `InterviewAnswerEntity` 一对多
- 与 `ResumeEntity` 多对一

---

### 2. InterviewAnswerEntity

对应数据库表 `interview_answers`，代表某次面试中一道题的用户答案和评估结果。

**核心字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | Long | 主键自增 |
| `session` | InterviewSessionEntity | 关联的会话（@ManyToOne LAZY） |
| `questionIndex` | Integer | 题号 |
| `question` | TEXT | 题目内容 |
| `category` | String | 能力分类 |
| `userAnswer` | TEXT | 用户答案 |
| `score` | Integer | 得分 0-100 |
| `feedback` | TEXT | 评估反馈 |
| `referenceAnswer` | TEXT | 参考答案 |
| `keyPointsJson` | TEXT | 关键知识点 JSON |
| `answeredAt` | LocalDateTime | 回答时间（@PrePersist 自动设置） |

**约束**：唯一约束 `(session_id, question_index)`，保证每道题只有一个答案记录。

> **注意**：不同于 `InterviewQuestionDTO`（内存中的题目+答案），此 Entity 是独立持久化的答案记录，支持逐题查询和评分更新。

## 二、Request — 前端输入请求体（2 个）

### 3. CreateInterviewRequest

创建面试会话的请求体。

| 字段 | 类型 | 校验 | 说明 |
|------|------|------|------|
| `resumeText` | String | 可选 | 简历文本，无简历时为空 |
| `questionCount` | int | @Min(3) @Max(20) | 题目数量 |
| `resumeId` | Long | 可选 | 关联已有简历 |
| `forceCreate` | Boolean | 可选 | 是否强制新建（忽略未完成会话） |
| `llmProvider` | String | 可选 | LLM 提供商 |
| `skillId` | String | @NotBlank | 面试主题 ID |
| `difficulty` | String | 可选 | 难度：junior / mid / senior |
| `customCategories` | List\<CategoryDTO\> | 可选 | JD 解析的自定义分类 |
| `jdText` | String | 可选 | JD 原文 |

支持两种创建模式：关联已有简历（`resumeId`）/ 无简历通用面试（`skillId`）。

---

### 4. SubmitAnswerRequest

提交答案的请求体。

| 字段 | 类型 | 校验 | 说明 |
|------|------|------|------|
| `sessionId` | String | @NotBlank | 会话 UUID |
| `questionIndex` | Integer | @NotNull @Min(0) | 题号 |
| `answer` | String | @NotBlank | 用户答案 |

同时用于正式提交（跳转下一题）和暂存（不跳转）两种场景。

---

## 三、Response — 前端输出响应体（2 个）

### 5. SubmitAnswerResponse

提交答案后返回给前端的响应体，前端据此决定继续答题还是跳转报告页。

| 字段 | 类型 | 说明 |
|------|------|------|
| `hasNextQuestion` | boolean | 是否还有下一题 |
| `nextQuestion` | InterviewQuestionDTO | 下一题内容 |
| `currentIndex` | int | 当前题号 |
| `totalQuestions` | int | 总题数 |
| `turnEvaluation` | TurnEvaluationDTO | 单轮评估（自适应模式） |
| `adaptiveDecision` | AdaptiveDecisionDTO | 决策结果（自适应模式） |
| `abilityProfile` | AbilityProfileDTO | 能力画像（自适应模式） |

提供两个构造器：
- **完整版**：含自适应评估三个字段
- **简化版**：仅基础字段，自适应字段为 null，用于自适应失败时的降级返回

---

### 6. ResumeAnalysisResponse

简历 AI 分析结果。位于 interview 包但由简历模块的 AI 评分功能使用。

| 字段 | 类型 | 说明 |
|------|------|------|
| `overallScore` | int | 总分 0-100 |
| `scoreDetail` | ScoreDetail | 5 维度评分详情 |
| `summary` | String | 简历摘要 |
| `strengths` | List\<String\> | 优点列表 |
| `suggestions` | List\<Suggestion\> | 改进建议列表 |
| `originalText` | String | 原始简历文本 |

**内嵌 Record：ScoreDetail**

| 字段 | 说明 |
|------|------|
| `contentScore` | 内容完整性 (0-25) |
| `structureScore` | 结构清晰度 (0-20) |
| `skillMatchScore` | 技能匹配度 (0-25) |
| `expressionScore` | 表达专业性 (0-15) |
| `projectScore` | 项目经验 (0-15) |

**内嵌 Record：Suggestion**

| 字段 | 说明 |
|------|------|
| `category` | 建议类别：内容/格式/技能/项目 |
| `priority` | 优先级：高/中/低 |
| `issue` | 问题描述 |
| `recommendation` | 具体建议 |

## 四、DTO — 内部数据传输对象（8 个）

### 会话相关（3 个）

#### 7. InterviewSessionDTO

前端交互的核心数据结构，表示正在进行的面试会话。

| 字段 | 类型 | 说明 |
|------|------|------|
| `sessionId` | String | 会话 UUID |
| `resumeText` | String | 简历文本 |
| `totalQuestions` | int | 总题数 |
| `currentQuestionIndex` | int | 当前题号 |
| `questions` | List\<InterviewQuestionDTO\> | 题目列表 |
| `status` | SessionStatus | 会话状态 |

内嵌 `SessionStatus` 枚举：`CREATED → IN_PROGRESS → COMPLETED → EVALUATED`

> **注意**：此 DTO 与 `InterviewSessionEntity` 不同，不含数据库字段（如 JSON 列），只包含前端需要的信息。

---

#### 8. SessionListItemDTO

面试记录列表页的轻量摘要，不含题目/答案等大字段。

| 字段 | 类型 | 说明 |
|------|------|------|
| `sessionId` | String | 会话 UUID |
| `skillId` | String | 面试主题 |
| `difficulty` | String | 难度 |
| `resumeId` | Long | 简历 ID |
| `totalQuestions` | int | 题数 |
| `status` | SessionStatus | 会话状态 |
| `evaluateStatus` | AsyncTaskStatus | 评估状态 |
| `evaluateError` | String | 评估错误 |
| `overallScore` | Integer | 总分 |
| `createdAt` | LocalDateTime | 创建时间 |
| `completedAt` | LocalDateTime | 完成时间 |

提供静态工厂方法 `from(InterviewSessionEntity)`，直接从 Entity 映射，不经过 Mapper。

---

#### 9. InterviewDetailDTO

面试详情页的完整数据，用于查看历史对话的全部信息。

**上层字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | Long | 主键 |
| `sessionId` | String | 会话 UUID |
| `totalQuestions` | Integer | 总题数 |
| `status` | String | 会话状态 |
| `evaluateStatus` | String | 评估状态 |
| `evaluateError` | String | 评估错误 |
| `overallScore` | Integer | 总分 |
| `overallFeedback` | String | 总体反馈 |
| `createdAt` | LocalDateTime | 创建时间 |
| `completedAt` | LocalDateTime | 完成时间 |
| `questions` | List\<Object\> | 题目列表（从 JSON 解析） |
| `strengths` | List\<String\> | 优势 |
| `improvements` | List\<String\> | 改进建议 |
| `referenceAnswers` | List\<Object\> | 参考答案 |
| `abilityProfile` | AbilityProfileDTO | 能力画像（来自 adaptive 模块） |
| `adaptiveTrace` | List\<AdaptiveTraceDTO\> | 自适应追踪链 |
| `answers` | List\<AnswerDetailDTO\> | 逐题答案详情 |

**内嵌 Record：AnswerDetailDTO**

| 字段 | 类型 | 说明 |
|------|------|------|
| `questionIndex` | Integer | 题号 |
| `question` | String | 题目 |
| `category` | String | 分类 |
| `userAnswer` | String | 用户答案 |
| `score` | Integer | 得分 |
| `feedback` | String | 反馈 |
| `referenceAnswer` | String | 参考答案 |
| `keyPoints` | List\<String\> | 关键知识点 |
| `answeredAt` | LocalDateTime | 回答时间 |

由 `InterviewHistoryService.getInterviewDetail()` 组装，通过 MapStruct 从 Entity 映射。

---

### 题目相关（2 个）

#### 10. InterviewQuestionDTO

贯穿整个答题流程的核心 DTO，表示一道面试题目。

| 字段 | 类型 | 说明 |
|------|------|------|
| `questionIndex` | int | 题号 |
| `question` | String | 题干 |
| `type` | String | Skill 分类 key，如 "MYSQL"、"DP" |
| `category` | String | 展示标签，如 "MySQL"、"动态规划" |
| `topicSummary` | String | 知识点摘要，如 "Redis RDB/AOF 持久化对比" |
| `userAnswer` | String | 用户答案（答题前为 null） |
| `score` | Integer | 得分 |
| `feedback` | String | 评估反馈 |
| `isFollowUp` | boolean | 是否追问 |
| `parentQuestionIndex` | Integer | 父题索引 |

**type 与 category 的区别**：`type` 是程序用的分类 key，`category` 是展示用的中文标签。

**不可变更新方法**：
- `withAnswer(String)` — 填充答案，返回新对象
- `withEvaluation(int, String)` — 填充评分和反馈，返回新对象
- `create()` 静态工厂 — 创建新题目

序列化后存入 `InterviewSessionEntity.questionsJson`，被出题服务、答题服务、评估服务共同使用。

---

#### 11. HistoricalQuestion

历史题目的轻量摘要，用于出题去重。

| 字段 | 类型 | 说明 |
|------|------|------|
| `question` | String | 原始题面 |
| `type` | String | Skill 分类 key |
| `topicSummary` | String | 知识点摘要 |

由 `InterviewPersistenceService` 从历史会话提取，被 `InterviewQuestionService` 用于构建"避免重复出题"的 Prompt 区段。`topicSummary` 为 null 时由调用方截取 `question` 前若干字兜底。

---

### 报告相关（2 个）

#### 12. InterviewReportDTO

面试评估报告的完整数据结构。

| 字段 | 类型 | 说明 |
|------|------|------|
| `sessionId` | String | 会话 UUID |
| `totalQuestions` | int | 总题数 |
| `overallScore` | int | 总分 0-100 |
| `categoryScores` | List\<CategoryScore\> | 各类别得分 |
| `questionDetails` | List\<QuestionEvaluation\> | 逐题评估 |
| `overallFeedback` | String | 总体评价 |
| `strengths` | List\<String\> | 优势 |
| `improvements` | List\<String\> | 改进建议 |
| `referenceAnswers` | List\<ReferenceAnswer\> | 参考答案 |
| `abilityProfile` | AbilityProfileDTO | 能力画像（自适应模式） |
| `adaptiveTrace` | List\<AdaptiveTraceDTO\> | 自适应追踪链 |

**内嵌 Record 一览**：

| 内部 Record | 字段 |
|-------------|------|
| `CategoryScore` | category、score、questionCount |
| `QuestionEvaluation` | questionIndex、question、category、userAnswer、score、feedback |
| `ReferenceAnswer` | questionIndex、question、referenceAnswer、keyPoints |

提供两个构造器：
- **完整版**：含 `abilityProfile` 和 `adaptiveTrace`
- **简化版**：自适应字段为 null/空列表，用于非自适应模式

---

#### 13. InterviewHistoryItemDTO

简历详情页展示关联面试记录的轻量摘要。

| 字段 | 类型 | 说明 |
|------|------|------|
| `id` | Long | 主键 |
| `sessionId` | String | 会话 UUID |
| `totalQuestions` | Integer | 题数 |
| `status` | String | 会话状态 |
| `evaluateStatus` | String | 评估状态 |
| `evaluateError` | String | 评估错误 |
| `overallScore` | Integer | 总分 |
| `createdAt` | LocalDateTime | 创建时间 |
| `completedAt` | LocalDateTime | 完成时间 |

由简历模块查询关联面试记录时使用，不含题目/答案，仅用于列表展示。通过 `InterviewMapper.toInterviewHistoryItem()` 映射。

## 五、调用关系总览

```
前 端
  │ POST /api/interview/create        → CreateInterviewRequest
  │ POST /api/interview/submit        → SubmitAnswerRequest
  │
  ▼ 响应
  │ GET  /api/interview/sessions      ← SessionListItemDTO
  │ POST /api/interview/create        ← InterviewSessionDTO
  │ POST /api/interview/submit        ← SubmitAnswerResponse
  │ GET  /api/interview/{id}/detail   ← InterviewDetailDTO
  │ GET  /api/interview/{id}/report   ← InterviewReportDTO
  │ GET  简历详情中的面试记录           ← InterviewHistoryItemDTO

Service 层
  │ InterviewSessionService
  │   ├── 创建会话 → CreateInterviewRequest → Entity → InterviewSessionDTO
  │   ├── 答题流程 → SubmitAnswerRequest → QuestionDTO → SubmitAnswerResponse
  │   ├── 列表查询 → Entity → SessionListItemDTO
  │   └── 生成报告 → InterviewReportDTO
  │
  │ InterviewHistoryService
  │   ├── 详情查询 → Entity + AnswerEntity → InterviewDetailDTO
  │   └── 历史列表 → Entity → InterviewHistoryItemDTO
  │
  │ InterviewQuestionService
  │   ├── 出题 → HistoricalQuestion(去重) → InterviewQuestionDTO
  │   └── 追问 → QuestionDTO(父题) → QuestionDTO(子题)
  │
  │ AnswerEvaluationService / EvaluateStreamConsumer
  │   └── 评估 → QuestionDTO[] → InterviewReportDTO

数据层
  InterviewSessionEntity ──(1:N)── InterviewAnswerEntity
          │
    [JSON 列]
    ├── questionsJson        ↔ List<InterviewQuestionDTO>
    ├── abilityProfileJson   ↔ AbilityProfileDTO
    └── adaptiveTraceJson    ↔ List<AdaptiveTraceDTO>
```

## 六、与 adaptive.model 包的交互

本包的 3 个 DTO 直接引用 `adaptive.model` 包的自适应相关类：

| 本包 DTO | 引用的自适应类 |
|---------|---------------|
| `InterviewReportDTO` | `AbilityProfileDTO`、`List<AdaptiveTraceDTO>` |
| `InterviewDetailDTO` | `AbilityProfileDTO`、`List<AdaptiveTraceDTO>` |
| `SubmitAnswerResponse` | `TurnEvaluationDTO`、`AdaptiveDecisionDTO`、`AbilityProfileDTO` |

自适应面试产生的数据最终通过这些引用融入标准面试流程的响应和报告中。
