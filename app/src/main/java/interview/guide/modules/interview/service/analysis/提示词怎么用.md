详细分析**为什么需要提示词**以及在**InterviewQuestionService**中提示词的具体作用：

## 🤖 **为什么需要提示词？**

### **A. AI的本质：没有内置知识**
```java
// AI模型本身没有关于"如何出题"的知识
// 需要通过提示词告诉AI：
// 1. 你是谁（角色）
// 2. 要做什么（任务）
// 3. 怎么做（方法）
// 4. 输出什么格式（格式）
```

### **B. 提示词的作用**
1. **角色设定**：让AI进入特定角色（面试官、技术专家等）
2. **任务明确**：告诉AI要完成什么具体任务
3. **约束条件**：限制AI的回答范围和风格
4. **格式规范**：确保AI输出符合预期格式
5. **质量保证**：通过详细指导提高AI回答质量

## 📋 **InterviewQuestionService中的提示词作用**

### **1. 四套提示词的分工**

#### **A. 技能相关提示词（无简历时使用）**
```java
// skillSystemPromptTemplate + skillUserPromptTemplate
// 用于：基于技能方向生成标准面试题
```

#### **B. 简历相关提示词（有简历时使用）**
```java
// resumeSystemPromptTemplate + resumeUserPromptTemplate  
// 用于：基于简历内容生成个性化面试题
```

### **2. 具体作用分析**

#### **A. 简历题生成流程**
```java
// 第一步：构建系统提示词
String systemPrompt = resumeSystemPromptTemplate.render()
    + buildSkillPersonaSection(skill)      // 技能角色设定
    + "\n\n" + outputConverter.getFormat(); // JSON格式要求

// 第二步：构建用户提示词
Map<String, Object> variables = new HashMap<>();
variables.put("questionCount", questionCount);      // 需要生成多少题
variables.put("followUpCount", followUpCount);      // 每题多少追问
variables.put("skillName", skill.name());           // 技能方向
variables.put("resumeText", resumeText);           // 简历内容
variables.put("historicalSection", historicalSection); // 历史题目

String userPrompt = resumeUserPromptTemplate.render(variables);
```

#### **B. 系统提示词的作用**
```java
// resumeSystemPromptTemplate.st 内容示例：
# Role
你是一位专业的技术面试官，擅长{skillName}方向的面试评估。

# Task
根据候选人简历内容，生成高质量的面试问题。

# Constraints
- 问题必须与简历内容相关
- 避免重复历史题目
- 每个问题生成{followUpCount}个追问
- 输出JSON格式

# Output Format
{
  "questions": [
    {
      "question": "具体问题内容",
      "type": "技术类型",
      "category": "技能分类",
      "followUps": ["追问1", "追问2"]
    }
  ]
}
```

#### **C. 用户提示词的作用**
```java
// interview-question-user.st 内容示例：
请根据以下简历内容，生成{questionCount}个关于{skillName}的面试问题：

## 简历内容
{resumeText}

## 历史题目（避免重复）
{historicalSection}

## 要求
1. 问题必须与简历中的技术栈相关
2. 每个问题生成{followUpCount}个追问
3. 考察候选人的实际项目经验
4. 难度适合{difficultyDescription}的候选人
```

### **3. 提示词如何影响AI输出**

#### **A. 角色设定影响**
```java
// 没有角色设定：
// AI可能随意回答，风格不一致

// 有角色设定：
// "你是一位专业的技术面试官"
// → AI回答会更专业、更有深度
// → 会使用面试官的口吻和思维方式
```

#### **B. 任务明确影响**
```java
// 模糊的任务：
// "请生成一些面试问题"
// → AI可能生成简单、不相关的问题

// 明确的任务：
// "根据候选人简历内容，生成高质量的面试问题"
// → AI会分析简历，生成相关的问题
// → 会关注简历中的技术栈和项目经验
```

#### **C. 格式规范影响**
```java
// 没有格式要求：
// AI可能自由发挥，输出格式不统一

// 有格式要求：
// "必须输出JSON格式"
// → 确保输出结构化，便于程序解析
// → 便于后续处理和存储
```

## 🎯 **具体场景分析**

### **场景1：有简历时的出题过程**

#### **提示词构建**
```java
// 系统提示词 = 基础模板 + 技能角色 + JSON格式
String systemPrompt = resumeSystemPromptTemplate.render()
    + buildSkillPersonaSection(skill)      // "你是Java高级面试官，有10年经验"
    + "\n\n" + outputConverter.getFormat(); // "必须输出JSON"

// 用户提示词 = 具体内容 + 变量
Map<String, Object> variables = Map.of(
    "questionCount", 10,
    "followUpCount", 2,
    "skillName", "Java后端",
    "resumeText", "张三有3年Java经验，做过Spring Boot项目...",
    "historicalSection", "已考过：多线程、Spring Boot"
);
String userPrompt = resumeUserPromptTemplate.render(variables);
```

#### **AI处理过程**
```
输入提示词：
"你是Java高级面试官，有10年经验
根据以下简历生成10个面试题：
张三有3年Java经验，做过Spring Boot项目...
已考过：多线程、Spring Boot
必须输出JSON格式"

AI内部处理：
1. 理解角色：我是Java面试官
2. 分析简历：找到Spring Boot、Java经验等关键词
3. 生成问题：
   - "请介绍Spring Boot的核心特性"
   - "你在项目中如何处理并发问题"
4. 生成追问：
   - "Spring Boot的自动配置原理是什么？"
   - "如何解决线程安全问题？"
5. 输出JSON格式
```

### **场景2：无简历时的出题过程**

#### **提示词构建**
```java
// 系统提示词包含通用模式
String systemPrompt = skillSystemPromptTemplate.render()
    + buildSkillPersonaSection(skill)
    + GENERIC_MODE_SYSTEM_APPEND           // "本次面试无候选人简历..."
    + outputConverter.getFormat();
```

#### **AI处理过程**
```
输入提示词：
"你是Java高级面试官，有10年经验
本次面试无候选人简历，请出该方向的标准面试题
禁止出现'你在简历中提到...'等表述
必须输出JSON格式"

AI内部处理：
1. 理解：没有简历，要出标准题
2. 避免提及简历相关内容
3. 生成通用Java题目：
   - "请解释Java中的多线程机制"
   - "Spring Boot的启动流程是怎样的"
4. 输出JSON格式
```

## 🔄 **提示词的工作流程**

### **1. 模板加载阶段**
```java
// 启动时加载.st文件
this.skillSystemPromptTemplate = loadTemplate(resourceLoader, "prompts/interview-question-system.st");
this.skillUserPromptTemplate = loadTemplate(resourceLoader, "prompts/interview-question-user.st");
```

### **2. 动态构建阶段**
```java
// 运行时动态构建
Map<String, Object> variables = buildVariables(...);  // 准备变量
String systemPrompt = template.render();               // 渲染系统提示词
String userPrompt = userTemplate.render(variables);     // 渲染用户提示词
```

### **3. AI调用阶段**
```java
// 发送给AI
QuestionListDTO dto = structuredOutputInvoker.invoke(
    chatClient, systemPrompt, userPrompt, outputConverter,
    ErrorCode.INTERVIEW_QUESTION_GENERATION_FAILED,
    "简历题生成失败：", "简历题", log);
```

### **4. 结果解析阶段**
```java
// 解析AI返回的JSON
List<InterviewQuestionDTO> questions = convertToQuestions(dto);
```

## 🎯 **提示词设计的核心原则**

### **1. 角色一致性**
```java
// 所有提示词都保持一致的面试官角色
"你是一位专业的技术面试官"
"你具备{skillName}方向的深度技术视野"
"你有10年以上的面试经验"
```

### **2. 任务明确性**
```java
// 明确告诉AI要做什么
"生成高质量的面试问题"
"避免重复历史题目"
"每个问题生成{followUpCount}个追问"
```

### **3. 格式规范性**
```java
// 强制JSON格式输出
"必须输出JSON格式"
"不要包含Markdown代码块"
"字段名称必须严格匹配"
```

### **4. 内容相关性**
```java
// 根据不同场景调整内容
有简历 → "基于简历内容生成问题"
无简历 → "生成该方向的标准面试题"
有JD → "根据职位描述出题"
```

## 💡 **总结：为什么必须用提示词？**

### **1. AI没有内置知识**
- AI不知道"如何出题"
- 不知道"面试应该问什么"
- 不知道"什么是好的面试问题"

### **2. 提示词相当于"工作说明书"**
```java
// 告诉AI：
// 你是谁 → 面试官
// 要做什么 → 生成面试题
// 怎么做 → 分析简历、避免重复、生成追问
// 输出什么 → JSON格式的问题列表
```

### **3. 确保输出质量**
```java
// 通过详细指导，让AI：
// - 理解面试的深度要求
// - 避免生成低质量问题
// - 保持回答的一致性
// - 输出可用的结构化数据
```

### **4. 支持个性化定制**
```java
// 通过变量替换，支持：
// - 不同技能方向
// - 不同难度级别
// - 不同候选人背景
// - 不同面试场景
```

**提示词是AI系统的"灵魂"**，它决定了AI如何理解任务、如何思考问题、如何生成回答。在InterviewQuestionService中，四套提示词的配合使用，实现了从"无标准答案"到"高质量个性化面试题"的完整流程。
