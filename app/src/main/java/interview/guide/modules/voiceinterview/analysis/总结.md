## 🎙️ 语音面试模块 (voiceinterview) 分析

### 📁 模块整体架构

这个模块实现了**完整的实时语音面试系统**，包含以下核心功能：

1. **WebSocket 实时通信** - 用户音频 ↔ AI 音频的实时双向传输
2. **语音识别 (ASR)** - 将用户语音转换为文字
3. **大模型对话 (LLM)** - 生成面试官回复
4. **语音合成 (TTS)** - 将回复文字转换为语音
5. **异步评估** - 面试结束后 AI 评估候选人表现

### 🔧 核心技术架构

#### **1. 核心处理管线**
```
用户音频 → ASR语音识别 → LLM大模型生成 → TTS语音合成 → AI音频推送
    ↓            ↓              ↓              ↓           ↓
  麦克风      文字内容      文本回复       语音回复     扬声器/前端
```

#### **2. 技术选型**
- **ASR/TTS**: 阿里云 DashScope (qwen3-asr-flash-realtime / qwen3-tts-flash-realtime)
- **LLM**: 通义千问 (qwen3.5-flash)
- **实时通信**: WebSocket
- **异步评估**: Redis Stream
- **数据库**: PostgreSQL + JPA

### ⭐ 核心组件详解

#### **1. VoiceInterviewWebSocketHandler (核心处理器)**

这是最复杂的组件，实现了完整的语音对话管线：

**主要功能**：
- WebSocket 连接管理
- 用户音频接收和 AI 音频发送
- ASR/STT 结果处理
- LLM 对话生成
- TTS 语音合成
- 会话状态管理（暂停/恢复/超时）

**关键特性**：

```java
// 1. 虚拟线程执行器（避免阻塞调度线程）
private final ExecutorService voicePipelineExecutor = 
    Executors.newVirtualThreadPerTaskExecutor();

// 2. 语音防抖合并（多段STT定稿后统一触发LLM）
// 用户说完一句话可能有多段VAD切段，需要合并后再处理

// 3. AI说话冷却期（防止回声）
private static final long AI_SPEAK_COOLDOWN_MS = 800; // 800ms

// 4. 句子级并发TTS（流式输出时每检测到一个完整句子就启动TTS）
```

**完整流程**：
```java
// handleTextMessage() 处理前端消息
case "audio":
    handleUserAudio(sessionId, audioData); // 接收用户音频
    break;

// handleSttResult() 处理识别结果
if (isFinalSegment) {
    // 最终识别结果，合并到缓冲区
    state.appendFinalSttSegment(recognizedText);
    flushMergedUtteranceToLlm(sessionId); // 触发LLM
}

// triggerLlmResponse() 生成AI回复
if (streamEnabled) {
    // 流式模式：边生成边TTS
    aiReply = llmService.chatStreamSentences(..., 
        partialText -> sendTextMessage(session, partialText), // 实时文本
        sentence -> ttsService.synthesize(sentence)  // 句子级TTS
    );
} else {
    // 非流式：等全部生成后再TTS
    aiReply = llmService.chat(userText, sessionEntity, conversationHistory);
    byte[] aiAudio = ttsService.synthesize(aiReply);
    sendAudio(session, wavAudio, aiReply);
}
```

#### **2. QwenAsrService (语音识别)**

基于阿里云 DashScope 的实时 ASR 服务：

**核心功能**：
- 启动/停止 ASR WebSocket 连接
- 发送音频数据
- 处理识别回调（部分结果/最终结果）
- 自动断句（VAD - Voice Activity Detection）
- 断线重连

**配置参数**：
```java
// application.yml 中的配置
qwen:
  asr:
    url: wss://dashscope.aliyuncs.com/api-ws/v1/realtime
    model: qwen3-asr-flash-realtime
    language: zh
    format: pcm
    sample-rate: 16000
    enable-turn-detection: true
    turn-detection-type: server_vad
    turn-detection-silence-duration-ms: 2000  // 静音2秒判定为一句话结束
```

### 🎯 高级特性

#### **1. 流式输出 + 并发 TTS**
```java
// 启用流式输出时
if (streamEnabled) {
    // LLM 流式输出期间，每检测到一个完整句子就启动 TTS
    Semaphore ttsSemaphore = new Semaphore(maxConcurrentTtsPerSession);
    llmService.chatStreamSentences(
        onSentence = sentence -> {
            ttsSemaphore.acquire();
            CompletableFuture<byte[]> future = CompletableFuture.supplyAsync(() -> {
                return ttsService.synthesize(sentence);  // 并发TTS
            });
        }
    );
}
```

#### **2. 语音防抖合并**
```java
// 用户可能连续说多段话（VAD自动切分）
// 需要等用户说完一句话（或超时）再触发LLM
state.appendFinalSttSegment(recognizedText);
// 等待 debounce 时间后，合并所有片段，统一触发LLM
```

#### **3. 回声消除**
```java
// AI说话时丢弃麦克风输入，防止回声触发识别
if (state.isAiSpeakingOrCooldown()) {
    return;  // 丢弃音频
}

// AI说完后还有800ms冷却期
private static final long AI_SPEAK_COOLDOWN_MS = 800;
```

#### **4. 暂停超时检测**
```java
@Scheduled(fixedRate = 30000)  // 每30秒检查
public void checkPauseTimeout() {
    if (elapsed > WARNING_TIME_MS) {  // 4:30
        sendPauseWarning(sessionId);  // 发送警告
    }
    if (elapsed >= PAUSE_TIMEOUT_MS) {  // 5:00
        handlePauseTimeout(sessionId);  // 超时暂停
    }
}
```

### 💡 技术亮点

1. **虚拟线程** - 使用 `Executors.newVirtualThreadPerTaskExecutor()` 处理阻塞 I/O
2. **句子级并发 TTS** - LLM 流式输出时并行合成语音，降低延迟
3. **智能防抖** - 语音识别结果合并机制，避免一句话触发多次
4. **回声消除** - AI 说话时禁用麦克风输入
5. **流式输出** - 文本先于音频到达，提升用户体验
6. **自动重连** - ASR 断线自动重连机制
7. **性能监控** - Micrometer 指标收集（延迟、成功率等）

这个模块是一个非常完整的实时语音交互系统，展示了如何将 ASR、LLM、TTS 三个 AI 能力无缝整合，提供流畅的语音面试体验！
