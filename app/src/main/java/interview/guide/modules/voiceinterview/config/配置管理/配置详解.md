## VoiceInterviewProperties.java 技术架构分析报告

### 1. 类的主要功能和定位

**VoiceInterviewProperties** 是语音面试模块的**核心配置管理类**，采用Spring Boot的`@ConfigurationProperties`模式，集中管理语音面试的所有配置参数。该类作为配置中心，为语音面试模块提供统一的配置访问入口，实现了配置与代码的分离。

### 2. 配置属性结构分析

该类采用**分层嵌套结构**，将相关配置按功能域分组：

#### 2.1 核心配置域
- **PhaseConfig**：面试阶段时长和题目数量配置
- **QwenConfig**：通义千问ASR/TTS服务配置（主要使用）
- **AliyunConfig**：阿里云语音服务配置（已废弃标记）
- **AudioConfig**：音频编解码参数
- **RateLimitConfig**：限流控制配置
- **OpeningConfig**：开场问题模板配置

#### 2.2 关键配置项说明
```java
// 核心业务配置
private int aiQuestionMaxChars = 120;           // AI回复最大字符数
private boolean llmStreamingEnabled = true;      // LLM流式推送开关
private int aiStreamPushIntervalMs = 180;      // 流式推送间隔
private int maxConcurrentTtsPerSession = 3;    // 每会话TTS并发上限

// 音频技术参数
private String codec = "opus";                   // 音频编解码格式
private int sampleRate = 16000;                  // 采样率
private int bitRate = 24000;                     // 比特率
private int channels = 1;                        // 声道数
```

### 3. 设计模式和框架特性

#### 3.1 采用的设计模式
- **配置对象模式**：将相关配置封装在内部类中，提高内聚性
- **Builder模式**：DurationConfig使用构造函数参数初始化
- **工厂模式**：通过@ConfigurationProperties自动创建配置实例

#### 3.2 Spring Boot框架特性
- **@ConfigurationProperties**：绑定配置文件前缀`app.voice-interview`
- **@Component**：注册为Spring Bean，支持依赖注入
- **类型安全**：强类型配置，避免字符串硬编码
- **环境变量支持**：通过${}占位符支持环境变量覆盖

### 4. 与其他模块的依赖关系

#### 4.1 依赖该类的核心服务
```java
// 主要依赖关系图
```

- **配置分层**：基础配置在application.yml，特定配置在voice-interview-opening.yml
- **动态覆盖**：通过环境变量实现配置的动态调整
- **配置隔离**：不同环境(dev/test/prod)使用不同配置值

### 5. 在系统架构中的作用

#### 5.1 配置管理中心
- **统一入口**：为语音面试模块提供单一配置访问点
- **配置验证**：通过类型检查确保配置正确性
- **默认值管理**：为关键参数提供合理的默认值

#### 5.2 模块解耦
- **配置与代码分离**：修改配置无需重新编译代码
- **环境适配**：不同环境使用不同配置文件
- **功能开关**：通过配置控制功能的启用/禁用

#### 5.3 技术参数管理
- **音频参数**：控制编解码格式、采样率等音频处理参数
- **服务配置**：管理第三方服务（阿里云DashScope）的接入参数
- **性能调优**：通过限流和并发控制优化系统性能
