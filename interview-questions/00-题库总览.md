# AI 面试项目题库总览

这套题库共包含 12 个技术章节、71 道项目面试题。内容以项目当前真实代码为依据，覆盖从简历上传、大模型调用、文字和语音面试，到 RAG、Redis、数据库、监控、测试及部署的完整链路。

## 12 个章节简介

| 章节 | 主要内容 | 复习重点 |
|---|---|---|
| 01 项目整体架构与技术选型 | 介绍项目解决的问题、模块化单体架构，以及 PostgreSQL、Redis、对象存储和 Java 21 虚拟线程的分工。 | 能够用一条完整业务链介绍项目，并说明主要技术选型的原因和边界。 |
| 02 大模型网关、结构化输出与 Skills | 介绍多 LLM Provider、三种 ChatClient、结构化 JSON 重试、动态配置、Prompt 防护和技能资源接入。 | 讲清楚模型调用如何统一管理，以及项目目前只有 Skills/工具接入、没有完整 Agent 编排。 |
| 03 简历上传、解析与异步分析 | 介绍文件校验、Tika 解析、内容哈希去重、S3 存储、Redis Stream 异步评分和失败处理。 | 掌握上传到分析结果的完整流程，以及事务提交后入队和异常误标完成的问题。 |
| 04 文字面试与自适应评估 | 介绍个性化出题、历史题去重、答案提交、能力画像、自适应决策和最终报告生成。 | 能够说明一次答题如何影响下一题，以及 Redis 会话和数据库之间的一致性边界。 |
| 05 RAG 与知识库 | 介绍文档向量化、pgvector 检索、查询改写、动态 topK、SSE 回答、多轮会话和 RAG 评测。 | 掌握文档上传到检索回答的完整链路，并区分已实现的检索评测与尚未实现的答案质量评测。 |

| 09 面试日程与提醒 | 介绍规则与 AI 解析邀请、提醒计划、定时扫描、邮件和站内通知，以及多实例认领。 | 掌握提醒生命周期，并说明自动派发默认关闭、邮件端到端幂等仍需增强。 |

## 建议复习顺序

第一遍先复习第 01 章，形成两到三分钟的项目整体介绍；第二遍重点复习第 02、04、05、06 章，掌握大模型、文字面试、RAG 和语音四条核心链路；第三遍复习第 07～11 章，用于回答 Redis、事务、安全、监控和测试等深入追问；最后通过第 12 章总结项目不足和生产化优化方向。

## 项目最重要的技术主线

项目以模块化 Spring Boot 单体为业务中枢，通过统一大模型网关调用不同 Provider，使用 PostgreSQL 保存事实数据、Redis 承担缓存和异步任务、S3 兼容存储保存原始文件，再分别构建文字面试、RAG 问答和实时语音三类 AI 应用。

当前项目的主要优势是业务功能和调用链较完整，异步任务、结构化输出、RAG、语音以及观测基础都有真实实现；主要不足是认证授权、高可用、完整事务消息、Prometheus/Grafana、WebRTC 和部分语音自动化测试尚未完整落地。
